# KMBID 搜标网站讲解片 · 分镜

- **一句话**：开明的同事小熊每天埋在几十个招标网站里找标，AI 小助手 Clawd 带来 kmbid.linzezhang.com，
  搜标变轻松、越用越准，公司多拿项目，大家的提成、奖金、绩效跟着涨。
- **观众**：商务部、销售部同事，内部分享与钉钉群转发。
- **规格**：1920×1080 横屏，24fps，62 秒，原创合成音乐 120 BPM，中文字幕（得意黑），开明 Logo 常驻左上角、片尾放大。
- **世界**：暖米色办公室 → 淡蓝的「网站里面」→ 深蓝夜晚 → 清晨金色 → 片尾暖米色。色彩随心情由灰暗转明亮。
- **母题**：纸堆。开头压垮小熊的纸堆，结尾变成桌上唯一一张整齐的卡片。
- **小熊情绪弧**：发愁 → 被砸懵 → 惊讶 → 期待 → 两眼放光 → 安睡 → 惊喜 → 认真 → 开心 → 欢呼。
- **Clawd**：讲解员。字幕出现时它张嘴「说」，用手指向要看的东西。
- **事实边界**（按 PPT）：网站负责搜标、整理、推送；判断与投标由人负责；收益以实际中标、项目利润与公司提成制度为准（片中小字标注）。
