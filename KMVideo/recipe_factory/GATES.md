# 质量闸门：每部片子都要过的固定层

配方决定「这部片子和别的片子哪里不一样」，本文件决定「这部片子够不够好」。两者分开：
因子取值再新，过不了这里就退回。

**权威顺序**：`workspace.yaml → paths.standard`（KMDY《通用基准.md》）＞ Owner 当轮要求 ＞ 本文件。
本文件是配方工坊对通用基准的执行解释，冲突时按通用基准。开工前读一次 `paths.editorial_gate`。
创作方法的原文在 `refs/`：《故事型广告 S1 创作基准》（品牌三线、服务即产品、肯定性叙述）与《KMDY 共同底座》（四要素退回条件、七维、研究与复盘口径）。

## 1. 固定层（所有配方共用，不参与抽样）

| 项 | 要求 |
|---|---|
| 叙事闭环 | 真实业务/设备问题 → 专业识别判断 → 开明对应能力 → 现场/项目证据 → 观众拿到答案与可信度。技术服务在故事里承担关键因果作用 |
| 品牌三线 | 同一组事件同时推进：观众的判断与情绪、人物对服务的需求与服务起的作用、观众对开明的认识 |
| 品牌识别 | 墨绿 / 米白 / 暖金；公司名；专业眉题；简短两级标题（问题 / 行动）。封面、第一帧、正文、结尾同题 |
| 事实 | 能力、效果、项目、数字、型号只用公司原件（`paths.evidence_root`）或有出处的资料，逐条写进配方 `facts`；缺项写 UNKNOWN。合同目标、过程实施、量测结果、签认验收、能力上限分开写。别家作品不算开明业绩 |
| 演绎边界 | 风格化角色（拟人设备、零件、卡通人物）可以创作情节并标明演绎；写实真人、事故、心理、危急情节只用真实来源。感染力来自真实处境与约束（停机窗口、工期、成本），而不是编出来的情绪 |
| 禁用表述 | 「工艺还原」及同义宣传；排他性说法（唯一、最好）只在原件支持时使用 |
| 合规 | 广告性质清楚；AI 生成内容按《人工智能生成合成内容标识办法》第 10 条主动声明并使用平台标识；服务效果与实际可实现条件对应（广告法第 8、14、28 条） |
| 字幕 | 透明底、真实粗字重、让出动作；有旁白时按实际音频排字幕 |
| 声音 | 原创合成（参照 `promo_30s/music.py`）或 `paths.music_library` 已授权曲目；无旁白时必须有完整声音设计。响度测量不等于试听，试听要有人耳 |
| 规格 | 1080×1920 竖屏、30fps、H.264 High + AAC、-14 LUFS、+faststart；平台 UI 安全区：顶部 250px、底部 350px、右侧 150px |
| 自检 | 先用 `engines/capture.py --sheet 20` 出接触表自查，再全量渲染 |

## 2. 精选四要素（每项都要及格，`value_core` 那项做到最强）

| 要素 | 片内可核的问题 | 退回条件 |
|---|---|---|
| 获得感 | 看完能多判断什么？正文给出依据了吗？ | 只提问题，或只说公司很强 |
| 惊喜感 | 新鲜的关系 / 视角 / 推进行为是什么？ | 换名词、换皮肤、同一反转模板 |
| 表达力 | 普通观众跟得上因果，专业观众不被误导吗？ | 字幕补不回的因果跳步、结构错误 |
| 感染力 | 真实处境、约束、选择和后果让人关心吗？ | 虚构人物、事故、情绪或意义 |

编剧自评四项各 1–5 分，每项写一句可证伪的依据；`value_core` 那项 ≥4，其余 ≥3。

## 3. 七维验收（质检 agent 逐项打分）

| 维度 | 看什么 |
|---|---|
| 内容价值 | 四要素是否成立，观众的收获是否具体 |
| 技术表达 | 工程原理、结构、工序是否正确，专业观众挑不出错 |
| 真实性 | `facts` 逐条有出处；演绎部分标明；无编造数字 |
| 品牌 | 品牌色、公司名、眉题、同题贯穿 |
| 视觉与声音 | 构图、节奏、字幕可读、安全区、声音设计与响度 |
| 叙事闭环 | 问题 → 判断 → 能力 → 证据 → 答案，环环相扣 |
| 稳定量产适配 | 代码可重跑、配方与产物路径完整、同车道下一部可复用手艺 |

状态分开登记，互不代替：`rendered`（技术成功）→ `qc_pass`（质检通过）→ `owner_accepted`（Owner 接受）→ `published`（平台回执）→ `metrics`（真实流量）。
七维满分是目标，由质检打分、Owner 验收，制作者不自行盖章。

## 4. 去同质化闸门（factory.py 自动执行）

1. 与全库每份配方 L0 至少 3 项不同（含 EXT 车道登记的 Blender 工作间成片）
2. (叙事母型, 惊喜机制, 画风) 三元组全库唯一
3. 同车道最近 4 部：叙事母型与惊喜机制都不重复
4. 同一批：未固定的 L0 取值出现次数 ≤ ceil(n/3)

闸门只管配方层面。质检 agent 另外看成片层面的趋同：同车道新片与最近 4 部并排拼接触表，
开头 2 秒、结尾 3 秒、标题句式任一处雷同就退回。
