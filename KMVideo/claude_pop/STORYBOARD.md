# 窑宝咯噔了 · 开明高新 × Clawd 手绘卡点宣传片（分镜）

仿照 Claude 官方 MV《I'm Upping My P(doom)》（KMOS Release `ClaudeVideo`）：手绘水彩 + 抖动墨线、小橙块 Clawd 当主角、
底部胶囊字幕、漫画拟声大字、一个贯穿全片的仪表道具（原片是 P(DOOM) 温度计，这里换成**百分表“跳动”表**），首尾呼应。

- 竖屏 1080×1920 · 24fps · 46s · 120 BPM（1 拍 0.5s，1 小节 2s）。时间唯一来源：`cues.js`。
- **一镜到底**：全片没有硬切。所有“转场”都是同一个镜头在同一个手绘世界里推、拉、甩、钻进气泡、升上云端再落回来。
- 抖音安全区：动作放在屏幕 y 150–1300；字幕胶囊中心 y≈1450；最下方 ~350px 留给平台 UI；右侧点赞栏附近不放关键信息。

**一句话**：水泥厂的回转窑“窑宝”轮带磨损、一转一咯噔，厂长以为只能拆窑停产两个月——天上掉下一个开明高新的箱子，
Clawd 蹦出来，**窑不停转、现场修好**，全厂跳起来。

**世界**：窑宝是一台端面朝镜头的回转窑（圆脸 = 筒体端面，外圈 = 轮带，下面两只托轮）。背景是水泥厂：预热器塔、筒仓、烟囱。
色彩弧：灰蓝阴天（病了）→ 紫色噩梦（气泡里）→ 金色晴天（修好）→ 粉蓝云端（规模）→ 暖橙黄昏（片尾）。

**母题**：①百分表“跳动”表：病时指针乱甩，修好后归零；②“咯噔”：开头是病，结尾最后一下是 Clawd 在轮带上蹦；
③厂长的热干面：前面被咯噔震飞，结尾安稳地吃。

**角色弧**：窑宝 难受 → 被“拆走”（噩梦）→ 被修 → 打嗝舒服 → 开心转。厂长 哆嗦 → 崩溃 → 惊 → 臭美（车屑呆毛）→ 喜极 → 安心吃面。
Clawd 惊喜登场 → 专注 → 酷（墨镜）→ 差点被齿圈咬 → 得意眨眼。

## 规则自检

- 每段都有事件与反应（有“起因 → 反应”顺序，不叠在同一时刻）。
- 字幕是用户明确要求的（仿原片底部胶囊字幕），中英双语；其余文字只有拟声词和片尾卡。
- 每个缝都有转场：iris 开 → 右移 → 钻气泡 → 气泡破 → 跟落 → 爆闪 → 下摇 → 甩镜 → 甩回 → 上摇穿云 → 下落穿云 → iris 收。
- 结尾呼应开头：同一台窑、同一个“咯噔”、同一碗热干面，意思反过来了。
