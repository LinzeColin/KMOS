## 二、数据从哪到哪

真实 Git 跟踪控制引用先派生同源守卫与最窄操作锁；步骤四重放已复核状态、重试、反压和锁生命周期证据，并在进程内执行一次获取、续租、有序释放与陈旧提交拒绝。释放后仅保留进程内墓碑版本，退出后不可恢复；不读业务数据、不写数据库或运行时文件。

## 三、关键参数为什么这么定

当前值和改哪里在 `06_运维手册.md`，这里只讲**为什么是这个值**。

| 参数 | 为什么定这个值 |
|---|---|
| 租约持续时间 | 本地安全边界，等于三个续租间隔；生产启用前必须由 `TASK-OPME-B-001` 校准。 |
| 续租间隔 | 本地安全边界，为租约持续时间的三分之一；续租保持栅栏令牌并递增锁版本。 |
| 过期宽限 | 本地安全边界，小于一个续租间隔；接管仍必须携带当前栅栏与完整锁版本证据。 |
| 获取超时 | 有限同步决策上限；当前切片从不休眠或阻塞等待。 |
| 最大等待 | 保持 Stage038 在入队前暂停，禁止隐藏等待队列。 |
| 重试抖动 | 保持 Stage039 重试所有权；锁竞争不消耗重试预算。 |
| 死锁超时 | 登记有限保护值；规范排序和全有或全无获取使当前切片不产生阻塞死锁。 |
