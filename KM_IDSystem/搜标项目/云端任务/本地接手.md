## 1. C1 平台普查（约 10 分钟）

1. `mkdir -p 本地产出/C1 && cp 产物/C1/平台普查.csv 本地产出/C1/平台普查_输入.csv`，在这份副本里给能找到的平台补 `列表页URL`（维修/检修/工程类公告列表或"招标公告"总列表）。不补也能跑，只测首页可达性，日均量写"数不出来"。
2. 跑：
   ```bash
   cd 产物/C1 && python3 平台探测.py --普查 ../../本地产出/C1/平台普查_输入.csv --输出 ../../本地产出/C1/平台普查.csv
   ```
3. 验收：≥60 行有 网址；每行 免登录看列表/反爬 不再是"没查"；有列表页的行 每天维修类公告估计 有数或写明"数不出来：原因"。

## 2. C2 下浮率（抓取约 1 小时，目标 ≥300 样本）

1. **扩链接**（种子只有 36 条；结果公告里同时写限价+中标价的比例不高，建议凑 800–1000 条）。
   **先把种子拷到 本地产出/ 再追加**——不要往受 git 跟踪的 产物/ 里写数据：
   ```bash
   cd 产物/公共
   mkdir -p ../../本地产出/C2 ../../本地产出/C3
   cp ../C2/候选链接.jsonl ../../本地产出/C2/候选链接.jsonl
   cp ../C3/候选链接.jsonl ../../本地产出/C3/候选链接.jsonl
   python3 列表抽链接.py --列表页 "<某站结果列表页，页码处写{页}>" --页 1-30 \
     --必含 "中标|成交|候选人|结果" --且含 "检修|维修|大修|维保|修复|安装|改造|技改|探伤|检测" \
     --输出 ../../本地产出/C2/候选链接.jsonl
   ```
   优先站点（搜索过程中出现的高产源，二手线索）：gigeps.com、国能e招 chnenergybidding.com.cn、三峡 eps.ctg.com.cn、中铝、sxzjtc.com、各省 ggzy「交易结果」栏目。聚合站（千里马/剑鱼/招标网）只作发现，能找到官方原文就换成官方 URL。
2. **抓取**（仍在 产物/公共）：`python3 抓取.py --输入 ../../本地产出/C2/候选链接.jsonl --缓存 ../../本地产出/C2原文`（默认 3 秒/次；可中断，重跑自动续；`--重试失败` 再试非 ok 的）
3. **解析+统计**：
   ```bash
   cd ../C2
   python3 解析结果.py --缓存 ../../本地产出/C2原文 --链接 ../../本地产出/C2/候选链接.jsonl --输出 ../../本地产出/C2
   python3 统计分布.py --样本 ../../本地产出/C2/下浮率样本.csv --输出 ../../本地产出/C2/下浮率分布.csv
   ```
   解析会打印跳过原因计数（无限价/费率报价/多标段配不上…），按原因决定补哪类链接。
4. **人工抽检 30 条**：随机抽 `下浮率样本.csv` 30 行对照原文核限价、中标价、标段；把错误率写进 C2/README.md。错误率 >10% 先修 `解析结果.py`/`抽限价.py` 再重跑，别带病出数。
5. 验收：质检=ok 样本 ≥300；`下浮率样本.csv` 按设计没有单位名/片段列，`解析明细.jsonl` 的片段已抹 `[单位]` 但仍属内部复核件，不外发。

## 3. C3 难例库（抓取 15 分钟 + 标注约 2–3 小时）

1. 扩链接（种子 121，"万元元混写"类 0 条，需补）：`cd ../公共`（从 产物/C2 回到 产物/公共），`python3 列表抽链接.py --列表页 "<招标公告列表页{页}>" --页 1-10 --必含 "招标|采购|比选|询价" --排除 "结果|中标|成交" --输出 ../../本地产出/C3/候选链接.jsonl`
2. 抓取（在 产物/公共）：`python3 抓取.py --输入 ../../本地产出/C3/候选链接.jsonl --缓存 ../../本地产出/C3原文`
3. 切片：`cd ../C3 && python3 生成待标注.py --缓存 ../../本地产出/C3原文 --输出 ../../本地产出/C3/待标注.jsonl`
4. **标注**：逐条读 `原文片段`，**独立**填 `正确答案`（格式 `[{"标段":"1"|null,"限价元":数值|null,"含税":true|false|null,"类型":"详见文件"(仅限价元为null时)}]`），标注状态改 `已标注`。答案口径：有"最高限价/控制价"就只写它，没有才写预算；单价限价也写（加 `"单位":"元/吨"`）。**不要照抄 预测**——评测的意义就在这。
5. 校验+评测：
   ```bash
   python3 标注校验.py --待标注 ../../本地产出/C3/待标注.jsonl --输出 ../../本地产出/C3/难例.jsonl
   python3 评测.py ../../本地产出/C3/难例.jsonl --错例 30
   ```
   把分组准确率写进 C3/README.md；错例值得修就修 `抽限价.py` 并把该条加进 `构造样例.jsonl`（保留回归）。
