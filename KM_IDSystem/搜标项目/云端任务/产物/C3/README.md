# C3 金额抽取难例库（抽取器已完成，真实难例待本地标注）

**做了什么**：写了一个只用标准库的参考抽取器 `抽限价(原文) -> list[dict]`。它覆盖 8 类难点：多标段、中文大写、万元/元混写、含税/不含税、详见文件、预算与限价并存、单价与总价并存、表格；另外会挡掉保证金、注册资本、业绩、电话、日期、编号这类干扰金额。每条结果输出标段、限价元（统一为元）、含税、类型、单位、依据、片段和存疑说明。云端打不开公告原文，所以**真实难例是 0 条**。配套交付了本地流水线：`生成待标注.py`（切 ≤200 字片段、自动打难点标签、预填预测）→ 人工独立标注 → `标注校验.py`（校验片段长度和字段，**逐个核对答案数字在片段里找得到，防编数**，达到 200 条才放行）→ `评测.py`（按难点标签分组报准确率）。

**关键数字**
- 构造样例 36 条（边写边调）：36/36。
- 盲测样例 20 条（写完后不改代码直接跑）：**原始 16/20 = 80%**。错在罗马数字标段、后置的含税说明（2 例）、"在开标时公布"。修复后 20/20，**之后它就不算盲测了**。
- 候选公告链接 121 条：大写 31／多标段 31／单价 21／预算 vs 限价 10／详见 10／含税 9／表格 9／**万元元混写 0**。整个会话的搜索额度已经用完，还差约 180 条。
- 离线测试：C3 单元测试 12 项＋全链路端到端 4 项（C1/C2/C3/公共各 1）全部通过。

**局限**：样例都是构造的（文件里有标注），**在真实公告上的准确率没测**，以本地难例的评测结果为准。
