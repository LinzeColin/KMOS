# C2 下浮率分布（工具版，样本待本地采）

**做了什么**：云端打不开招标站，**样本数 0**。交付一条流水线，在国内网络下即可出数：`列表抽链接.py` → `抓取.py`（3 秒一次，可断点续跑，识别登录／验证码／瑞数／限流）→ `解析结果.py`（抽限价和中标价、按标段配对、算下浮率、抹掉单位名）→ `统计分布.py`（评标办法×类型×金额档，给 P25/P50/P75 和样本数）。

**关键数字**
- 候选结果公告 **36 条**，原样来自搜索结果。按标题核查：约 9 条是物资采购、1 条是招标公告，另有 15 条来自聚合站。离 300 条样本还差 **300**，搜索额度已用完。
- 高产源线索：gigeps.com、国能 e 招、三峡 eps.ctg.com.cn、陕西中技、剑鱼各省站；中铝只在搜索过程中出现过。
- 离线测试：5 个构造页出 4 个样本，下浮率与手算一致。

**口径**：限价优先取最高限价／控制价，只有预算时标"预算(代限价)"；中标价没有时取第一候选人报价。同一标段有多个限价时，依次按"税口径一致 → 无存疑 → 金额大"选。下浮率在 0～60% 之外记"异常"，永远不进统计。费率报价跳过，并写明原因。

**局限**：真实页的准确率**没测**，本地需抽 30 条人工核对。

**复审**：独立 agent 找出 3 个会静默出错数的问题，已修并加了回归测试："RMB"金额被读成 0、"存疑"盖掉"异常"、配对误取"含暂列金"分项。
