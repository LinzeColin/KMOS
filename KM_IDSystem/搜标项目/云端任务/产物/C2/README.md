# C2 公开开标结果的下浮率分布（工具版，样本待本地采）

**做了什么**：云端打不开任何招标网站（出网策略拦截），所以**云端产出的样本数为 0**。已交付的是一条可离线验证的流水线，到国内网络下就能出数：
`列表抽链接.py`（从任意结果列表页抽维修类链接）→ `抓取.py`（限速 3 秒、断点续跑、识别登录/验证码/瑞数/加速乐）→ `解析结果.py`（抽限价与中标价，按标段配对，算下浮率，抹掉中标单位名）→ `统计分布.py`（评标办法 × 项目类型 × 金额档，给 P25/P50/P75、样本数和边际分组）。

**关键数字**
- 候选结果公告链接 **36 条**（检修维修 27／技改 5／安装 2／检测 2），全部原样来自搜索结果，没有打开核实。目标 300 条样本，还差 **300 条**。整个会话的搜索额度（200 次）已经用完。
- 高产来源线索（二手，出自搜索过程）：广西投资集团 gigeps.com、国能 e 招、三峡 eps.ctg.com.cn、中铝、陕西中技、剑鱼各省子站。
- 端到端离线测试：5 个构造页面（含瑞数反爬页、费率报价页），出 4 个样本，下浮率与手算一致；费率页记为跳过；单位名脱敏有专项断言。

**口径**：限价优先取"最高限价/控制价"，只有预算时标"预算(代限价)"；中标价没有明确金额时，取"第一中标候选人报价"，并在口径列注明；下浮率不在 0～60% 之间的记"异常"，不进统计；费率报价跳过并写明原因。

**局限**：解析是规则法，真实页面的准确率**没测**，本地要抽 30 条人工核对。

**复审**：见文末。
