# C1 集团电子采购平台普查（工具版，待本地探测）

**做了什么**：云端出网被环境策略拦截（ggzy/ccgp/cebpubservice/各集团平台均 403），只能用搜索引擎拿平台名单与网址。整理出 `平台普查.csv` 初版，并写了在国内网络下回填其余列的 `平台探测.py`。

**关键数字（2026-09-23 实数）**
- 有网址的平台 **87 个**（按域名去重）：集团 SRM 43（电力 11／有色 9／化工 8／水泥 8／钢铁 7）、省 ggzy 32、省政府采购网 7、全国公开门户 5。
- 证据级别：77 个网址就是平台官方域名（一手，但**只在搜索结果中出现，未打开**），10 个是二手页面。
- 另有 11 行"查了没有"或"只有第三方镜像"：华新、山水、华菱、恒力、广东能源、申能、云南铜业、洛阳钼业没搜到自建平台；亚泰、华电只搜到镜像站；河北省政府采购网的官方入口没核实。
- 免登录、需注册、反爬、日均维修类公告量这几列：**全部没查**，列里标的是"没查（云端出网被拦）"。要等本地探测后才能按日均量排序。

**怎么用**：先给重点平台补"列表页URL"，再在本地运行 `python3 平台探测.py --普查 平台普查.csv --输出 ../../本地产出/C1/平台普查.csv`（依赖 `../公共/`）。探测失败的行一律写"数不出来＋原因"，不会写成 0。

**局限**：日均量按列表页首屏里的日期跨度来估，只是量级参考；平台是 JS 渲染或需要登录时，就写"数不出来"。

**复审**：见文末。
