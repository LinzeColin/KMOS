# C1 集团电子采购平台普查（工具版，待本地探测）

**做了什么**：云端出网被拦（招标站全部 403），只能靠搜索拿平台名单。产出 `平台普查.csv` 初版（由 `生成普查初版.py` 按统一规则从 `搜索记录/` 复现）和本地回填用的 `平台探测.py`。

**关键数字**
- 有官方网址平台 **88 个**：集团 SRM 44（电力 11／化工 9／有色 9／水泥 8／钢铁 7）、省 ggzy 29、省政府采购网 9、全国门户 5、省工程交易中心 1。中国建材 2 个域名计 2 行。
- 证据：一手 78（网址原样出现在搜索结果里，**未打开**）、二手 10。
- 另外 11 行没有官方网址：8 家没搜到自建平台；亚泰、华电、安徽只搜到镜像站。
- 免登录／注册／反爬／日均维修类量：**全部没查**，需本地探测后才能排序。

**用法**：先补 `列表页URL`，再运行 `python3 平台探测.py --普查 平台普查.csv --输出 ../../本地产出/C1/平台普查.csv`。探测失败写"数不出来＋原因"，不会写 0。

**局限**：日均量只看列表首屏，量级参考；统计口径是维修／检修／安装／改造／检测。

**复审**：独立 agent 复核，数字与文件一致，没有编造。发现的问题都已修：镜像站和一手／二手判定前后不一、易派客网址写错、分类错、限流页和空页被当成 ok、零星旧日期拉低日均。"搜索记录"是子 agent 整理后的结论，不是原始搜索页，所以一手只代表"链接出现过"。
