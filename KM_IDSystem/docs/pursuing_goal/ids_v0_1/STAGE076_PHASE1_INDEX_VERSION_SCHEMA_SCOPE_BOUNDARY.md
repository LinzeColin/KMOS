# Stage076 Phase 1 · 索引版本 Schema 范围、输入输出与边界确认

## 本轮目标

只将冻结的 `STAGE-076_索引版本Schema.md`、Stage075 Review 与既有控制合同投影为一份静态工程合同。合同定义 `fulltext`、`vector`、`hybrid` 三类索引版本、`active_index_pointer`、`building_index_version`、影子候选、切换前验证和回退条件；不构建、切换、查询或持久化任何索引。

## 唯一权威与输入

- 冻结 Stage076 任务包是本阶段范围和验收的唯一来源。
- Stage075 Review 与 Stage075 P1 静态合同只作为已完成的前序控制证据。
- 不建立第二权威事实源；来源文档与业务线白箱人工复核仍是唯一业务权威。
- 不读取、打开、解析、复制、移动或修改真实资料、原始元数据、manifest、证据账本、审计日志、报告或物理索引。

## 静态输出合同

1. `index_versions` 的未来记录固定八个字段：版本、索引类型、生命周期、资料范围引用、切块计数、模型引用、导入引用和创建时间引用。
2. `active_index_pointer` 对每种索引类型只能指向一个已通过切换前验证的候选；未来切换必须是原子的。
3. 每次未来批量导入必须产生新的 `building_index_version`，不得覆盖活动版本；旧索引在构建期间继续服务。
4. 影子候选与活动服务隔离，在通过切换前验证前不得服务检索。
5. 新索引未通过、缺失或未记录切换前验证结果时，不得切换活动指针；失败候选不得替换旧索引。
6. 未来回退只能指向保留的上一活动版本；本阶段不执行任何回退。

## 本阶段不做

- 不实现数据库 schema、后台构建、索引写入、影子索引、切换、回退、检索或并发读取。
- 不读取真实资料，不执行批量导入，不选择 provider 或模型，不消耗模型 Token，不调用外部 API。
- 不创建持久化记录、审计记录、缓存、队列、索引 manifest 或已交付报告。
- 不启动 Stage076 P2、P3、P4、整阶段复审、OVH、生产、上传或推送。

## 验收与停止

本阶段只验收静态合同、聚焦用例、机器事实投影、中文生成视图与可撤回范围的一致性。任何真实资料访问、索引构建或切换、数据库连接、持久化、模型调用、Agent、OVH、生产、上传或超出 Stage076 P1 的修改都会停止本阶段。

## 回退与下一门

只撤回本 P1 的范围说明、静态合同、聚焦用例、机器事实投影、治理路线、生成中文视图和本地回执，恢复到 `REVIEWED_EXTERNAL_API_COVERAGE_AUDIT_RUNTIME_DISABLED`。不影响真实资料、manifest、证据账本、审计日志、报告、数据库、索引、GitHub、OVH 或应用状态。下一步仅可在新的独立 run 进入 `IDS-STAGE076-P2-GATE`。
