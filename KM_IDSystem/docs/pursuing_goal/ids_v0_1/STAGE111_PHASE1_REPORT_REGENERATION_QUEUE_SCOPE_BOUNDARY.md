# Stage111 · 报告重新生成队列 Phase 1 范围与控制边界

## 目标与入口

- 任务：`IDS-V0_1-STAGE111-P1`
- 入口门禁：`IDS-STAGE111-P1-GATE`
- 后续门禁：`IDS-STAGE111-P2-GATE`
- 冻结输入：Stage111 任务包与 Stage110 报告质量评分整阶段复审控制工件。

本 Phase 只定义报告重新生成队列的未来控制形状。触发原因覆盖资料撤回、证据降级、证据冲突与索引版本变化；每个未来队列条目保持报告证据绑定、外部增强章节、人工确认、报告快照、影响分析、质量评分与重新生成状态的可审阅控制引用。

## P1 固定控制合同

- 报告关键结论保持 `evidence_id` 或 `evidence_gap` 的严格二选一；证据等级、引用来源、外部增强底层来源类型与业务线白箱确认保持独立控制引用。
- PDF 报告的未来交付合同要求显示引用来源；Stage110 已复审的引用页码控制继续作为前序控制语义保留。
- 报告生成快照固定 `data/index/evidence/model/generated_at` 五个未来组件，并与报告快照控制引用分离。
- 报告影响分析、报告质量评分、受影响报告、报告状态影响、队列进入原因和队列状态只承载未来控制标签；业务线白箱确认承担未来真实决策、重新生成与撤回的授权入口。
- 外部增强章节保持外部来源身份，不能成为内部项目依据、替代报告证据绑定或关闭 `evidence_gap`。

## 单一权威与运行时边界

- 冻结任务包与 Stage110 Review 控制工件构成本 Phase 的唯一工程控制上下文；来源文档、真实证据账本、已交付报告与业务线白箱人工复核继续承担业务事实权威。
- 本 Phase 产物是静态合同和白箱用例。真实资料、外部参考、报告、PDF、引用内容、快照、影响结果、质量分数、人工确认、审计、数据库、模型 Token、Agent、OVH、生产与正式上传保持后续授权范围。
- 队列创建、重新生成、撤回、报告状态更新、快照保存和持久化均由 P2 及后续独立 run 承接；本 run 保持零运行时计数。

## 验收、停止与回滚

- 聚焦用例必须验证控制引用、五项生成快照、PDF 引用来源、外部增强来源分离、人工确认、影响和队列状态控制，以及零运行时边界。
- 发现第二权威事实源、真实队列执行、真实报告或 PDF 生成、持久化、模型/Agent/OVH/生产动作，或 P2 被提前进入时，合同以失败状态关闭并停留在 `IDS-STAGE111-P1-GATE`。
- 回滚只撤回本 P1 的范围说明、静态合同、聚焦用例、machine run、治理投影、中文视图与交接，恢复 Stage110 Review 的本地零运行时状态；来源文档、真实证据账本、已交付报告、审计日志、数据库、GitHub、OVH 与应用状态保持原有边界。
