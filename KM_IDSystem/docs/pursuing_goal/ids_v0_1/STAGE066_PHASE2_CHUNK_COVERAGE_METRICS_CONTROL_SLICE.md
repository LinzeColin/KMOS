# STAGE-066 Phase 2：Chunk 覆盖率指标最小控制切片

## 当前结论

本步骤只执行 \`IDS-V0_1-STAGE066-P2\` 的纯内存、非业务、reference-only 控制切片。它严格复用
Phase 1 的十二字段输入和十七字段输出形状，以四条固定控制请求分别覆盖工程步骤、验收条款、
参数表和未知分母关闭；输出只保留不透明控制引用、指标标签和业务线白箱人工复核标记，不读取、
打开、解析、切分、计算或创建任何真实资料、页面、chunk、hash、覆盖率、未覆盖页面、质量结果、
索引或业务结论。

## 最小可运行边界

切片只接受一个包含四条固定控制请求的内存对象。每条请求必须完全匹配 Phase 1 的十二个引用字段
并维持既定顺序；新增字段、重排、未知控制场景或篡改任何控制引用都会被拒绝。控制场景只验证
指标字段、来源追溯形状和失败关闭的接线，不能解释为对真实文档、页面、章节、表格或来源内容的
覆盖率判断。

输出固定十七字段，保留 \`document_ref\`、\`page_ref\`、\`section_ref\`、
\`parser_output_ref\`、\`table_context_ref\` 和 \`source_fragment_ref\` 六维控制引用。
\`parse_coverage_ratio\`、\`chunk_coverage_ratio\` 和 \`uncovered_page_refs\` 都是
\`:control:\` 标签：没有实际比率、实际页码、实际未覆盖页、真实分母或真实覆盖率计算。
工程步骤、验收条款和参数表三类受保护语义面仍保持原子，不能被覆盖率字段或控制标签覆盖。

## 低可信与人工处理

四条控制记录均标为低可信并要求业务线白箱人工复核。未知分母控制记录明确关闭指标输出；
其余三条仅证明受保护语义面和追溯字段的控制形状，不证明真实解析覆盖率、Chunk 覆盖率、未覆盖
页面、质量或来源反查。来源文档和业务线人工复核始终是权威，控制标签、模型文本或本切片不得成为
第二权威事实源或业务决策依据。

## 禁止动作与回滚

不得读取真实资料、授权 fixture、正文、物理路径、实际页码、章节、表格、parser 输出、页面集合
或来源片段；不得执行真实 parser、章节检测、切块、身份/版本/hash 生成、语义分类、覆盖率计算、
未覆盖页识别、质量回归、质量降级、来源追溯、embedding、索引、数据库、Agent、模型、OVH、生产、
Phase3、整阶段复审、批次复审、上传或推送。

回滚只允许移除本 P2 范围说明、纯内存模块、控制合同、聚焦用例、machine run、事件、机器事实投影、
治理路线和生成中文视图，回到 \`PHASE1_CHUNK_COVERAGE_METRICS_CONTRACT_RUNTIME_DISABLED\`。
真实资料、manifest、evidence ledger、audit log、已交付报告、事实库、数据库、索引、GitHub、OVH
与应用状态不在回滚范围内。

## 后续门

本步骤通过后的唯一后续门为 \`IDS-STAGE066-P3-GATE\`，且必须由新的独立 run 进入。
