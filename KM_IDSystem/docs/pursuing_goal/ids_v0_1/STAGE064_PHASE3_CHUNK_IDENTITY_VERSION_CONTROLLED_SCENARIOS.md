# Stage064 Phase 3 · Chunk 身份与版本专项控制场景

## 当前目标

在 Stage064 P2 的三条固定、非业务、仅引用身份与版本控制记录上，机械重放六类冻结任务包专项场景：长文档、跨页参数表、施工步骤、参数表、引用页码反查与重复 chunk 的 embedding/索引边界。每一条结果都只保留控制引用形状和中文人工白箱处置；不读取、打开、解析、切分、计算、生成或保留真实文档、页面、章节、表格、来源片段、parser 输出或 chunk。

## 固定控制范围

- 只复用 P2 的三条十四字段 `:control:` 身份与版本控制记录；它们仍不是实际 `chunk_id`、`chunk_hash`、`document_id`、页码、章节或版本。
- 六类场景均为控制元数据，严格对应冻结任务包的专项验证面，但不代表真实长文档质量、跨页表格关系、施工步骤完整性、参数表边界、页码反查或重复 chunk 已经被验证。
- 每个场景保留六维控制追溯引用：文档、页码、章节、parser 输出、表格上下文和来源片段。引用不包含真实路径、URL、正文、页面内容、章节文本、表格内容或 parser 输出。
- 重复 chunk 场景只确认该纯内存控制模块没有发起 embedding 或索引写入；它不检测真实重复项、不验证实际身份或 Hash，也不形成真实去重效果结论。

## 场景与人工处置

| 控制场景 | 控制结论 | 人工白箱处置 |
| --- | --- | --- |
| 长文档 | 固定引用不足以确认真实切块质量 | 核验章节边界与版本依据 |
| 跨页参数表 | 不自动拼接、拆分或确认跨页关系 | 核验表格完整性与跨页上下文 |
| 施工步骤 | 不允许因身份或版本标签任意断开 | 核验步骤原子性与边界 |
| 参数表 | 不允许把控制标签当成字段或表格事实 | 核验参数表边界与来源 |
| 引用页码反查 | 控制页码不是实际原文位置 | 核验原文页码、章节与来源片段 |
| 重复 chunk | 不发起 embedding 或索引写入 | 核验真实重复、身份、Hash 与写入许可 |

## 可执行边界

- 允许：P2 控制记录的字段形状验证、六类固定场景重放、明确人工处置、控制追溯引用形状检查、禁止控制模块发起 embedding/索引写入的断言、中文反馈和失败关闭。
- 不允许：真实资料或 fixture 访问、真实 parser/章节检测/切块、实际 `chunk_id` 生成、实际 `chunk_hash` 计算、真实版本或来源绑定、实际切块质量验证、真实重复检测/去重、embedding、索引、数据库、持久化、Agent、模型调用、模型 Token、服务、OVH、生产、上传或推送。
- 来源文档和业务线白箱人工复核持续保持唯一权威；控制场景、控制记录和模型文本都不能成为业务事实、决策结论或第二权威事实源。

## 验收与回滚

- 聚焦用例必须证明 P2 的三条固定控制记录可重放为六类显式人工处置，全部场景覆盖任务包专项面、静默丢弃为零、六维控制追溯引用保持形状，并且重复场景未发起 embedding 或索引写入。
- 对被篡改的 P2 结果、缺失场景、非控制引用或任一副作用标记，场景报告必须失败关闭。
- 回滚只撤回本 P3 说明、场景合同、纯内存模块、聚焦用例、machine run、事件、事实投影、治理路线和生成中文视图，恢复到 `PHASE2_CHUNK_IDENTITY_AND_VERSION_CONTROL_SLICE_RUNTIME_DISABLED`。
- 不触及真实资料、`00_ORIGINAL_RAW_DATA`、manifest、evidence ledger、audit log、已交付报告、事实库、索引、数据库、GitHub、OVH 或应用状态。
