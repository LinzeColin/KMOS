# Stage109 Phase 2 报告影响分析受控最小切片

## 本轮目标

Stage109 P2 以 P1 的静态报告影响分析合同为唯一前序，形成可机械执行、可测试和可回滚的纯内存控制切片。切片覆盖报告证据绑定、章节输出形状、五项生成快照、引用资料更新、资料撤回、证据降级、索引版本变化、受影响报告、报告状态影响、质量评分、导出审计、模板限制、重新生成和撤回的未来控制引用。

## 固定控制输入

- 固定五条非业务、reference-only 控制请求。
- 每条请求固定 35 个输入字段：control_scenario、binding_mode 与 P1 的 33 个控制引用。
- 每条关键结论严格二选一关联 evidence_id_ref 或 evidence_gap_ref，并保留 evidence_grade_ref、citation_source_ref、citation_page_ref 与 human_confirmation_item_ref。
- 五条控制请求分别覆盖引用资料更新、资料撤回、证据降级、索引版本变化和受影响报告生命周期；所有引用保持不透明控制标签。

## 纯内存投影

每条请求机械投影四组控制记录，共 101 个字段、五条共 505 个检查点：

1. 报告证据绑定与章节输出形状。
2. data/index/evidence/model/generated_at 五项生成快照形状。
3. 报告影响分析、生命周期、质量评分、导出审计、模板限制、重新生成与撤回形状。
4. 外部增强来源语义与业务线白箱人工确认门禁。

这些投影仅描述后续授权工作应具备的输入、状态与审计形状。它们不读取来源资料，不读取或写入证据账本，不生成报告或 PDF，不保存快照，不写导出审计，也不形成业务结论。

## 阶段边界

- P3 才验证资料撤回、证据降级与索引版本变化的受控专项场景。
- P4 才交付报告样例、报告快照、质量评分、影响分析、模板限制和重新生成／撤回说明的交付控制证据。
- Stage109 Review 才机械复审 P1 至 P4 的冻结控制工件。
- 本 run 止于 IDS-STAGE109-P3-GATE。

## 停止与回滚

任何输入漂移返回 CONTROL_INPUT_MISMATCH，且不形成控制投影或持久化记录。回滚只撤回本 P2 的范围说明、纯内存模块、合同、聚焦用例、machine run、治理投影、生成中文视图、变更日志和交接，恢复到 P1 的 PASS_REPORT_IMPACT_ANALYSIS_CONTRACT_RUNTIME_DISABLED；P1、Stage108 Review、冻结任务包、来源资料、真实证据账本、已交付报告、审计日志、数据库、GitHub、OVH 与应用状态保持原状。
