# STAGE-062 Phase 1：表格证据绑定范围、输入输出与边界确认

## 当前结论

本步骤只定义 `IDS-V0_1-STAGE062-P1` 的静态表格证据绑定合同。唯一合同上下文是冻结
Stage062 任务包和 Stage061 已完成本地复审工件；Stage057 的 XLSX/CSV 接入、Stage058 的
Schema 推断、Stage059 的事实抽取、Stage060 的 RAG 摘要与 Stage061 的数据质量测试继续保持
各自唯一职责。本步骤只登记未来绑定请求、未来绑定结果、字段语义、数值边界、人工处理、失败
关闭和回滚边界；没有读取、打开、解析、推断、抽取、验证、绑定、写入、复制、移动或删除任何
真实表格、生产记录、质检记录、工作表、单元格、事实、证据或业务资料。

`evidence_id`、`document_id`、`sheet`、`row`、`column` 和 `source_uri` 是未来接口的固定字段
名，当前仅可承载不含正文、物理路径、实际 URI、单元格值或业务内容的受控引用。尤其
`source_uri` 只定义为不透明来源引用标识，不能在本步骤填入真实 URL、文件路径、网络位置或
来源正文。字段名、枚举和计数不是证据记录、文档、表格位置、字段映射、数值、日期、单位、
设备、材料、质量结果、事实类型或统计结论，因此本步骤不建立第二权威事实源。

## 输入、结果输出与数值边界

未来绑定请求固定为十九个非内容引用或接口字段，其中六个必需绑定维度为
`evidence_id`、`document_id`、`sheet`、`row`、`column` 和 `source_uri`。文件格式仅预留
`XLSX`、`CSV`，记录类型仅预留生产记录和质检记录；输入不保存来源正文、物理路径、实际 URI、
工作表、表头、单元格、公式或真实事实值。

未来绑定结果固定为十七个引用或界面接口字段，状态只能表达 future candidate、未绑定、拒绝或
人工处理需要；本步骤没有创建绑定结果、证据记录、来源定位、数据库 schema、事实或质量结果。
字段语义固定覆盖字段类型、数值引用、单位、日期、设备、材料、质量结果、事实类型和主键引用，
但不执行字段识别、单位或日期标准化、设备或材料解析、质量评估、事实类型推断或主键解析。

数值统计未来只能基于同时具备六个绑定维度的受控结构化事实。来源文档始终保持权威；模型不得
根据文本猜测数值、单位、日期、设备、材料、质量结果、事实类型或统计结论，RAG 摘要不得替代
结构化事实、成为数值统计依据或产生另一权威事实源。

## 失败、中文反馈与回滚

缺少事实引用、`evidence_id`、`document_id`、`sheet`、`row`、`column`、`source_uri`、字段类型、
单位或日期引用、质量结果或事实类型，或数值无法验证时，未来流程必须停止并交由人工处理；当前
没有实际失败或绑定结果。不能自动写入业务事实、证据账本、数据库、审计日志、报告或生产状态。

中文反馈只说明静态合同已定义、未来绑定必须可追溯以及待人工处理边界，不承诺自动绑定、来源
可用性、统计准确率、数据库可用、OVH 可用或生产可用。

回滚仅允许移除本步骤的范围说明、静态合同、聚焦用例、machine run、事件、机器事实投影和
生成中文视图，恢复到 `STAGE061_REVIEWED_LOCAL_STRUCTURED_DATA_QUALITY_RUNTIME_DISABLED`。真实
资料、manifest、evidence ledger、audit log、已交付报告、事实库、数据库、运行状态、GitHub、OVH
与应用状态不在回滚范围内。

一旦需要真实 XLSX/CSV、生产记录、质检记录、fixture、文件检测、解析器、表格解析、实际字段
识别、实际事实抽取、typed value、真实来源定位、真实证据绑定、数值统计、数据库、Agent、模型、
OVH、生产、Phase2、整阶段复审、批次复审、上传或推送，立即停止本步骤。
