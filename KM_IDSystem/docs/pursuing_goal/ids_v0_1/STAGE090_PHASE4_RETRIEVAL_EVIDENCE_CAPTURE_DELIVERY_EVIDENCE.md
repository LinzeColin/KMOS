# Stage090 Phase 4 · 从检索捕获证据交付控制证据、回滚与中文反馈

## 本轮目标

本阶段只从 Stage090 P3 的七条固定、非业务、reference-only 异常场景派生可机械核验的交付控制记录：evidence ledger 样例、证据等级报告、撤回影响清单、回归测试、不可作为结论依据的证据类型、证据降级说明、撤回与恢复说明及中文反馈。全部记录只存在于函数返回值，业务事实继续由来源文档、真实证据账本与业务线白箱人工复核裁定。

## 唯一权威与运行边界

- 冻结 Stage090 任务包、Stage089 Review、Stage090 P1/P2/P3 控制工件构成唯一合同上下文。
- P4 只重放 P3 场景中的不透明控制引用。控制记录不包含来源正文、真实路径、真实证据、真实 OCR、真实版本、真实风险、真实报告或真实恢复结果。
- 真实资料、原始元数据、fixture、manifest、检索结果、evidence ledger、audit log、回答、报告、数据库和物理索引保持受保护状态。
- 检索、证据捕获、OCR 评估、版本比较、冲突裁决、风险评分、可信等级变更、撤回、隔离、恢复、报告状态更新、模型、Agent、OVH、生产与上传保持在后续授权范围。
