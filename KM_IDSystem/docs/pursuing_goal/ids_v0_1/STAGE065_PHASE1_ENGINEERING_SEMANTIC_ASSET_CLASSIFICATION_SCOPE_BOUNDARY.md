# STAGE-065 Phase 1：工程语义资产分类范围、输入输出与边界确认

## 当前结论

本步骤只定义 `IDS-V0_1-STAGE065-P1` 的静态工程语义资产分类合同。唯一合同上下文是冻结
Stage065 任务包、Stage064 已完成本地整阶段复审工件和 Batch061-070 上传锁。合同只登记未来
`procedure`、`risk`、`acceptance`、`material`、`equipment`、`case`、`bid_response` 资产类型标签，
以及未来分类记录的受控引用、保护语义面、失败关闭、中文反馈和回滚边界；没有读取、打开、分类、
生成、写入或删除任何业务资料、原始元数据、parser 输出、文档、页面、章节、表格、来源片段、
chunk、身份、哈希、版本、分类记录、索引或嵌入。

七类资产类型仅是未来 schema 的受控标签，不填入任何真实 chunk、来源或业务结论。`document_ref`、
`page_ref`、`section_ref`、`parser_output_ref`、`table_context_ref` 和 `source_fragment_ref` 均为不透明
受控引用，当前不得填入正文、物理路径、URL、页码值、章节名称、表格内容或来源片段。

## 输入、结果输出与追溯边界

未来分类输入固定为十二个仅引用字段，未来分类记录固定为十六个静态 schema 字段。`semantic_asset_type`
和 `semantic_asset_subtype` 仅是未来字段标签，当前不对任何资料、chunk、工程步骤、验收条款、参数表、
材料、设备、案例或投标响应作出分类。未来记录必须保留 document、page、section、parser output、表格
上下文和来源片段六维引用，当前追溯绑定数为零。

工程步骤、验收条款和参数表是三类保护语义面：不得被任意切断，资产分类也不得覆盖或绕过其边界。
长文档、跨页参数表、来源追溯不完整或类别依据无法确认时，未来流程必须关闭并交由业务线人工白箱处理。

来源文档与经授权的业务线人工复核始终保持权威；分类标签、模型输出或本合同不得替代来源形成事实、
决策结论或第二权威事实源。

## 失败、中文反馈与回滚

缺少 chunk 身份/版本、章节感知切块、document、page、section、parser output、来源片段或资产类型目录
引用，遇到保护语义面，或未获授权执行分类时，未来流程必须关闭并转人工处理；当前没有任何实际失败、
输入、分类记录、分类标签、来源定位或处置记录。不得自动写入事实库、证据账本、数据库、索引、报告、
生产状态或业务线结论。

回滚只允许移除本步骤的范围说明、静态合同、聚焦用例、machine run、事件、机器事实投影、治理路线和
生成中文视图，恢复到 `STAGE064_REVIEWED_LOCAL_CHUNK_IDENTITY_AND_VERSION_RUNTIME_DISABLED`。真实资料、
manifest、evidence ledger、audit log、已交付报告、事实库、数据库、索引、GitHub、OVH 与应用状态不在
回滚范围内。

一旦需要真实资料、授权 fixture、实际 parser 输出、实际切块、实际身份/版本、真实语义资产分类、
覆盖率、质量回归、质量降级、索引、embedding、Agent、模型、OVH、生产、Phase2、整阶段复审、批次复审、
上传或推送，立即停止本步骤。
