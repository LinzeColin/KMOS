# Stage079 Phase 3 · 索引原子切换专项验证与异常场景

## 当前结论

`IDS-V0_1-STAGE079-P3` 只重放 P2 的五条固定、非业务、`reference-only` 原子切换控制投影，并以六条专项观察覆盖候选构建未完成的失败关闭、冒烟失败、切换失败、回退候选、后台构建期间并发检索隔离，以及 Operations／报告快照中的索引版本控制可见性。

P2 不含真实或模拟的物理索引构建失败记录。因此冻结任务包所列“索引构建失败”在本 run 中严格限定为既有 `CONTROL_CANDIDATE_BUILD_NOT_COMPLETE` 的失败关闭状态；它不被改写为真实构建失败。来源文档和业务线白箱人工处理继续是唯一权威。

## P3 专项验证范围

- 候选构建未完成和冒烟失败均阻断未来切换候选，旧活动版本控制投影保持连续服务；
- 切换失败后，控制投影的活动版本仍等于原活动版本；
- 回退候选只引用保留的上一活动版本，未执行实际回退；
- “并发检索不受影响”只由活动指针未变、旧版本持续服务、候选隔离和零实际检索动作组成的控制隔离条件表示；
- 每条 P2 索引版本控制记录都派生一条 Operations 视图投影和一条报告快照投影；二者只显示不透明控制引用，未写入真实界面或报告；
- 六条专项观察均有显式处置、业务线白箱人工处理前置和零静默丢弃。

## 本步骤明确不做

- 不读取、打开、复制、解析、保留、写入、查询、删除或修改真实资料、原始元数据、fixture、manifest、evidence ledger、audit log 或已交付报告；
- 不执行批量导入、数据库 schema 或连接、后台构建、索引构建、影子索引、实际冒烟测试、活动指针读写、检索、并发服务、回退、Operations 写入、报告快照写入、provider／模型选择或调用、模型 Token、Agent、OVH、生产、上传或推送；
- 不进入 P4、整阶段复审或 GitHub 上传。

## 验证、停止与回滚

聚焦用例重放 P2 固定输入，核对六类专项观察、六组 P2 记录形状、十条控制展示投影、活动版本连续性、回退目标和零运行时标志。P2 形状损坏、场景错序、构建未完成或冒烟失败候选未被阻断、活动版本变化、展示投影缺失或任何运行时标志为真时，均失败关闭且不进入 P4。

回滚只撤回本 P3 范围说明、场景合同、纯内存场景模块、聚焦用例、本地 run、事件、机器事实、治理路线和生成中文视图，恢复到 `PHASE2_ATOMIC_INDEX_SWITCH_CONTROL_SLICE_RUNTIME_DISABLED`；不会改变 P1/P2、冻结任务包、真实资料、fixture、manifest、evidence ledger、audit log、数据库、索引、GitHub、OVH 或应用状态。
