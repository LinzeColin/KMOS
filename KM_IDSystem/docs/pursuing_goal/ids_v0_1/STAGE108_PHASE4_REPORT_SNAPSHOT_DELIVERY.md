# Stage108 P4 · 报告快照交付证据、回滚与中文反馈

## 目标与输入边界

- 任务：`IDS-V0_1-STAGE108-P4`
- 入口门禁：`IDS-STAGE108-P4-GATE`
- 下一门禁：`IDS-STAGE108-REVIEW-GATE`
- 依据：冻结 `STAGE-108_报告快照.md`、Stage108 P1/P2/P3 控制工件与 Stage107 Review 已复审人工确认事项章节控制工件。

本 phase 仅从 P3 的五条固定、非业务、`reference-only` 场景派生 metadata-only 交付控制记录。来源文档、真实证据账本、已交付报告与业务线白箱人工复核继续承担业务事实权威；交付元数据仅描述控制状态，不形成第二权威事实源。

## 交付控制形状

- 报告样例、报告快照、报告质量评分、报告影响分析、报告模板限制与业务线白箱人工确认各 `5` 条，字段形状依次为 `17/13/13/15/14`。
- 报告重新生成与撤回说明各 `1` 条，共 `2` 条、每条 `14` 字段。
- 总计 `388` 个 metadata-only 字段检查点、`17` 类失败关闭和 `4` 条中文反馈。

报告样例始终保留关键结论与 `evidence_id_ref` 或 `evidence_gap_ref` 的严格二选一，及证据等级、引用来源、引用页码和索引版本控制引用。报告快照维持报告、索引版本与报告状态影响的控制关联；质量评分和影响分析维持业务线白箱复核前置。

## 任务包专项边界

- 资料撤回、证据降级和索引版本变化仅表达未来报告状态影响复核要求，保持真实报告状态不变。
- 外部增强保留外部公开参考与模型推理的来源语义，不能写成内部项目依据、替代证据绑定或关闭 `evidence_gap`。
- 模板限制、人工确认和最终结论保持业务线白箱门禁；人工确认未记录，最终结论未发布。
- 重新生成与撤回说明固定指向版本化、可验证的 P3 回退目标；两项生命周期动作保持未执行。

## 运行边界、失败关闭与回滚

交付模块只处理控制引用：它不读取、列举或处理真实资料、原始元数据、外部参考、模型推理、报告、PDF、证据账本、审计日志、数据库或物理索引；不生成报告、PDF、引用、快照、评分、影响分析、状态、审计或业务结论；模型 Token、Agent、OVH、生产、正式全局上传与推送保持零执行。

P3 场景形状、运行时边界、关键结论绑定、报告状态影响、外部增强来源分离、白箱确认、控制引用或交付形状发生漂移时，模块返回失败关闭报告：零交付记录、全零运行时计数和全 false 运行时标志。

回滚只撤回本 P4 的范围说明、纯内存交付模块、静态合同、聚焦用例、machine run、机器事实投影、治理路线、事件、生成中文视图与交接，返回 `PASS_REPORT_SNAPSHOT_CONTROLLED_SCENARIOS_RUNTIME_DISABLED`。Stage108 P1/P2/P3、Stage107 Review、冻结任务包、来源文档、真实证据账本、已交付报告、审计日志、数据库、GitHub、OVH 与应用状态保持原状。

本 run 止于 `IDS-STAGE108-REVIEW-GATE`；整阶段 Review、Stage109、正式全局上传、OVH 与生产继续由后续独立门禁承接。
