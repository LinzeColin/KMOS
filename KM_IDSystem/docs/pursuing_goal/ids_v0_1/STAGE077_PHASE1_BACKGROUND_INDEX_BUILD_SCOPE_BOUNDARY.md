# Stage077 Phase 1 · 后台索引构建范围、输入输出与边界确认

## 本轮目标

只将冻结的 `STAGE-077_后台索引构建.md` 与已复审的 Stage076 索引版本合同投影为一份静态工程合同。合同定义未来批量导入后的后台构建触发、构建中候选、旧活动索引持续服务、冒烟测试门、原子切换条件和回退保留边界；不启动后台任务，不构建、切换、查询或持久化任何索引。

## 唯一权威与输入

- 冻结 Stage077 任务包是本阶段范围和验收的唯一来源。
- Stage076 Review、Stage076 P1 静态合同及其已复审的索引版本 Schema 只作为前序控制证据；Stage077 不重定义或替代索引版本 Schema。
- 不建立第二权威事实源；来源文档与业务线白箱人工复核仍是唯一业务权威。
- 不读取、打开、解析、复制、移动或修改真实资料、原始元数据、manifest、证据账本、审计日志、报告、数据库或物理索引。

## 静态输入输出合同

1. 未来后台构建只在未来批量导入完成后由 `source_import_ref`、`document_scope_ref`、`chunk_count`、`embedding_model_ref`、`index_kind` 与 `candidate_index_version_ref` 六个不透明控制字段描述。
2. 每次未来批量导入必须为候选新版本建立后台构建计划，不得覆盖活动版本；旧活动索引在构建期间继续服务。
3. 候选构建必须与活动服务隔离；在未来冒烟测试完整通过前不得成为检索服务版本。
4. 未来原子切换只在构建完成、资料范围、切块计数、模型引用、候选隔离和服务连续性均已声明且冒烟测试通过后才可发生；失败、缺失或未记录结果时活动指针保持不变。
5. 未来回退只可指向保留的上一活动版本；本阶段不执行任何构建、冒烟测试、切换、检索或回退。

## 本阶段不做

- 不实现或启动数据库 schema、后台任务、索引写入、影子索引、冒烟测试、切换、回退、检索或并发读取。
- 不读取真实资料，不执行批量导入，不选择 provider 或模型，不消耗模型 Token，不调用外部 API。
- 不创建持久化记录、审计记录、缓存、队列、索引 manifest、实际日志、Operations、报告快照或已交付报告。
- 不启动 Stage077 P2、P3、P4、整阶段复审、OVH、生产、上传或推送。

## 验收与停止

本阶段只验收静态合同、聚焦用例、机器事实投影、中文生成视图与可撤回范围的一致性。任何真实资料访问、后台构建、索引切换、数据库连接、持久化、模型调用、Agent、OVH、生产、上传或超出 Stage077 P1 的修改都会停止本阶段。

## 回退与下一门

只撤回本 P1 的范围说明、静态合同、聚焦用例、机器事实投影、治理路线、生成中文视图和本地回执，恢复到 `REVIEWED_INDEX_VERSION_SCHEMA_RUNTIME_DISABLED`。不影响真实资料、manifest、证据账本、审计日志、报告、数据库、索引、GitHub、OVH 或应用状态。下一步仅可在新的独立 run 进入 `IDS-STAGE077-P2-GATE`。
