# Stage081 Phase 2 · 影子索引控制切片边界

## 目标

在不读取任何 IDS 业务资料、不访问保护目录、不创建第二权威事实源的前提下，
实现一个固定输入、纯内存、reference-only 的影子索引控制切片。切片投影未来
索引版本、后台构建、影子隔离、冒烟测试、未应用原子切换和未应用回滚资格，
用以验证冻结 Stage081 任务包要求的字段、失败关闭和旧活动版本连续服务；它不
构建、查询、切换或回滚真实索引。

## 唯一依据与范围

- 冻结任务包：`STAGE-081_影子索引合同.md`。
- 已完成前置：Stage081 P1 静态影子索引合同，以及 Stage080 Review/P1--P4 已审核
  索引回滚控制工件。
- 引用只用于控制标签和字段形状；不读取上述文件所指向的真实索引、数据库、
  导入资料、原始元数据或业务线内容。
- 不新增业务规则、文档范围、嵌入模型或索引版本的权威事实；业务线白箱人工
  处理只以未来例外的 reference-only 前置表达。

## 固定控制输入

输入严格固定为五条 `:control:stage081-p2:` 控制请求。每条请求的 `chunk_count`
为 0，所有引用均为不透明控制标签，候选、活动、上一活动和影子索引引用两两
隔离。五个场景仅是非业务测试标签：

1. 已通过冒烟门的影子索引切换候选，仍不执行切换。
2. 后台构建未完成，活动版本保持不变。
3. 影子冒烟测试失败，切换被关闭且活动版本保持不变。
4. 计划原子切换失败，活动版本保持不变。
5. 指向保留上一活动版本且仍在控制窗口内的影子索引回滚候选，仍不执行回滚。

每条索引版本控制记录固定记录冻结任务包要求的七个字段：
`index_version`、`index_kind`、`lifecycle_state`、`document_scope_ref`、
`chunk_count`、`embedding_model_ref`、`source_import_ref`。

## 控制投影与失败关闭

切片只在内存中投影索引版本记录、候选后台构建与影子隔离、活动指针、冒烟测试
输入与输出、未应用的原子切换候选和未应用的回滚请求资格。候选构建未完成、
冒烟输入缺失、冒烟失败、候选或影子不隔离、计划切换失败、回滚目标不是保留的
上一活动版本、回滚窗口无效，均必须关闭切换或回滚；活动指针投影始终保持原
活动版本，旧活动版本连续服务。

## 严格禁止

不得读取或写入真实索引、数据库、文件、网络、外部 API、模型、Agent、OVH 或
生产环境；不得启动后台构建、实际冒烟、检索、并发检索、切换、回滚或自动业务
写入；不得创建持久化记录、实际 manifest、冒烟日志、切换记录、回滚证明、
Operations 或报告快照；不得上传 GitHub 或 push。P3、P4、整阶段审查和 Stage082
均不在本 run 范围内。

## 验收与回退

P2 仅在以下本地证据齐全时完成：静态合同可解析、固定控制输入与输出字段完全
匹配、五个场景保持活动指针、失败关闭、回滚仅指向保留上一活动版本，且所有
运行边界为 false。回退只撤回本 P2 的范围说明、控制合同、纯内存切片、测试和
机器事实投影，恢复到 `PASS_SHADOW_INDEX_CONTRACT_RUNTIME_DISABLED`；不得触及
源数据、持久状态、OVH 或 GitHub。下一步只能在新的独立 run 中进入
`IDS-STAGE081-P3-GATE`。
