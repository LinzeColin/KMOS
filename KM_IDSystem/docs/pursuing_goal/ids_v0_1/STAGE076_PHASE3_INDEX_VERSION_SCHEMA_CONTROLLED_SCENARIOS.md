# STAGE-076 Phase 3：索引版本 Schema 专项验证与异常场景

## 当前结论

`IDS-V0_1-STAGE076-P3` 只重放 P2 的五条固定、非业务、`:control:` 索引版本控制投影，并以六个专项观察覆盖构建失败、冒烟验证失败、切换失败、回退、构建期间旧活动版本持续服务、并发检索隔离，以及 Operations／报告快照中的索引版本可见性。构建失败与冒烟验证失败分别观察同一条 P2 失败投影的构建状态和验证状态；这不会新增事实或制造第二条记录。

本步骤只产生内存中的控制场景结果与控制展示投影。它不构建、切换、查询、回退或持久化实际索引，也不写入实际 Operations 或报告快照。来源文档与业务线白箱人工复核继续是唯一权威。

## P3 专项验证范围

- P2 的失败构建状态与失败验证状态均阻断候选切换，旧活动版本保持服务；
- 构建中候选不替换活动版本；“并发检索不受影响”仅以活动指针未变、旧版本持续服务和零实际检索动作组成的控制隔离条件表示；
- 切换失败后结果活动版本仍等于原活动版本；
- 回退候选只引用保留的上一活动版本，未执行实际回退；
- 每条 P2 控制版本记录均派生一条 Operations 视图投影和一条报告快照投影，二者只显示不透明控制引用，未写入真实界面或报告；
- 六条专项观察均有显式处置、业务线白箱人工处理前置和零静默丢弃。

## 本步骤明确不做

- 不读取、打开、复制、解析、保留、写入、查询、删除或修改真实资料、原始元数据、fixture、manifest、evidence ledger、audit log 或已交付报告；
- 不执行批量导入、数据库 schema 或连接、索引构建、影子索引、冒烟测试、活动指针读写、检索、并发服务、回退、Operations 写入、报告快照写入、provider／模型选择或调用、模型 Token、Agent、OVH、生产、上传或推送；
- 不进入 P4、整阶段复审或 GitHub 上传。

## 验证、停止与回滚

聚焦用例重放 P2 固定输入，核对六类专项观察、五组 P2 记录形状、十条控制展示投影、活动版本连续性、回退目标和零运行时标志。P2 形状损坏、场景错序、失败候选切换未被阻断、活动版本变化、展示投影缺失或任何运行时标志为真时，均失败关闭且不进入 P4。

回滚只撤回本 P3 范围说明、场景合同、纯内存场景模块、聚焦用例、本地 run、事件、机器事实、治理路线和生成中文视图，恢复到 `PHASE2_INDEX_VERSION_SCHEMA_CONTROL_SLICE_RUNTIME_DISABLED`；不会改变 P1/P2、冻结任务包、真实资料、fixture、manifest、evidence ledger、audit log、数据库、索引、GitHub、OVH 或应用状态。
