# Stage099 P3 · 内部依据与外部增强分离专项验证与异常场景

## 当前范围

本 Phase 重放 Stage099 P2 自身生成的六条固定、非业务、`reference-only` 控制投影，形成六条、每条 28 字段、共 168 个检查点的纯内存异常场景。P3 聚焦验证：

- 检索文档保持 evidence 身份，文档内提示词不能覆盖 IDS 规则；
- 无内部依据时保持 `evidence_gap` 与独立来源类型，不伪装为内部经验；
- 高风险工程建议、合同承诺和生产写回进入业务线白箱人工处理，最终结论保持未发布。

P2 的 `6 / 19 / 4 / 35 / 210` 固定控制形状作为前序合同。P3 投影五个控制视图、六条人工处理要求和十五类失败关闭。回答结构、Prompt 版本、模型版本、查询、索引、所选 evidence、外部增强意见与人工确认门禁均只承载既有不透明控制引用。

## 权威与边界

冻结 Stage099 任务包、Stage099 P1、Stage099 P2 与 Stage098 Review 构成本轮控制上下文。来源文档和业务线白箱人工复核保持唯一业务事实权威；P3 不建立第二权威事实源。

本轮不读取或创建真实资料、提示词、查询、检索结果、回答、证据账本、审计记录、数据库或物理索引；不执行模型、模型 Token、Agent、OVH、生产、持久化、GitHub 上传或推送。P4、整阶段复审与 Stage100 保持未进入。
