# Stage116 · 复核审计 Phase 1 范围、输入输出与控制边界

## 目标与入口

- 任务：`IDS-V0_1-STAGE116-P1`
- 入口门禁：`IDS-STAGE116-P1-GATE`
- 后续门禁：`IDS-STAGE116-P2-GATE`
- 冻结输入：Stage116 任务包与已完成的 Stage115 Review 复核 UI 控制工件。

本 Phase 将“谁复核、何时复核、复核结果和影响范围”固定为全局中文、可审阅、可回滚的静态复核审计控制合同。合同承接 Stage115 已复审的队列、状态、审计、影响预览、外部增强来源分离和业务线白箱门禁；合同保持控制引用语义，并为后续独立授权的实现、接入与运行提供明确边界。

## P1 固定复核审计控制合同

- 输入与输出只包含 future-control reference：复核审计事件、复核队列项、触发类型、复核前后状态、复核动作、actor、time、reason、old value、new value、review result、证据可信等级前后、报告质量分前后、报告状态影响、影响范围、外部增强来源、业务线白箱确认、重新复核与归档。
- 低 OCR 置信度、资料冲突、解析失败和证据风险分别保留进入未来 `pending_review` 的控制路由。本 Phase 固定路由形状，为后续业务线白箱授权的真实评估保留入口。
- 状态集固定为 `pending_review`、`confirmed`、`rejected`、`needs_more_material`、`archived`；中文状态文本固定为“待复核”“已确认”“已拒绝”“需补资料”“已归档”。`submit_for_review`、`confirm`、`reject`、`request_more_material`、`archive` 保留为未来复核动作标签。
- 每次未来复核审计事件固定保留队列、触发、复核前后状态、动作、actor、time、reason、old value、new value 和 review result 控制引用。复核结果的影响范围固定指向 evidence trust level、报告质量分、报告状态和影响范围控制引用。
- 外部增强保持外部来源身份；业务线白箱确认继续承担真实状态转换、真实影响写回、人工确认和最终业务结论的前置门禁。

## 单一权威与运行时边界

- 冻结 Stage116 任务包与 Stage115 Review 复核 UI 工件构成本 Phase 的唯一工程控制上下文。来源文档、真实证据账本、已交付报告、既有审计日志与业务线白箱人工复核继续承担业务事实权威。
- 本 Phase 产物是范围说明、静态复核审计控制合同、聚焦用例、治理投影和本地回执。真实资料、OCR、冲突、解析、证据风险、复核队列、复核 UI、复核审计、证据可信等级、报告质量分、报告状态、数据库、人工确认、模型 Token、Agent、OVH、生产和正式上传保持后续授权范围。
- 本 run 保持零运行时计数：审计事件、状态转换、影响写回、持久化、数据库连接、模型、Agent、OVH 和生产运行均由后续阶段的独立授权承接。

## 验收、停止与回滚

- 聚焦用例验证二十二个 future 审计控制引用、四类未来入队路由、五个固定状态、五个未来动作标签、十二个审计字段、八个影响范围字段、中文状态反馈、外部增强来源分离、业务线白箱门禁和零运行时边界。
- 冻结 Stage115 Review 工件、任一触发、任一状态、审计 actor/time/reason/old/new/result、证据可信等级影响、报告影响、影响范围、外部增强来源分离或业务线白箱门禁出现缺口时，合同在 `IDS-STAGE116-P1-GATE` 收束并保留失败状态。
- 实际资料处理、复核审计、持久化、证据或报告影响、数据库、人工确认、模型、Agent、OVH、生产和正式上传继续等待后续授权；本 P1 完成后由 `IDS-STAGE116-P2-GATE` 定义下一独立 run。
- 回滚只撤回本 P1 的范围说明、静态复核审计控制合同、聚焦用例、machine run、治理投影、中文视图与交接，恢复 Stage115 Review 的本地零运行时状态；来源文档、真实证据账本、已交付报告、既有审计日志、数据库、GitHub、OVH 与应用状态保持既有边界。
