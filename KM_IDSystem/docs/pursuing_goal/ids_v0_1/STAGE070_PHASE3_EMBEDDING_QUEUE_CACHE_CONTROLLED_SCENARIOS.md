# STAGE-070 Phase 3：Embedding 队列与缓存专项验证

## 目标与范围

本切片只重放 Phase 2 的五条固定、非业务、reference-only `:control:` 记录，验证策略继承后的外发边界、队列/缓存/失败重试处置、预算暂停和审计投影前置关系。

来源文档继续是唯一权威；场景报告、控制引用、队列状态、缓存状态、重试状态、成本与审计字段均不能成为业务事实或自动决策依据。业务线策略例外仍须白箱人工复核。

## 专项验证合同

- `denied` 不形成外发载荷引用，并同时关闭队列、缓存和重试。
- `summary_only` 只保留摘要引用类别；document 将全文权限收紧为摘要时，不得升级为文本块引用类别。
- `full_text_allowed` 只保留文本块引用类别；它只是未来候选，仍不持久化、不调度、不调用 provider。
- 预算不足时，队列、缓存和重试都必须暂停；不得形成外部任务或外发载荷。
- 每条控制场景均须有完整 18 字段审计投影；每个未来外部调用候选均须先有审计投影，包含策略原因、provider/model 引用、零 Token/成本、chunk 引用和队列引用。
