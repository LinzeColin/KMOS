# Stage078 Phase 1 · 索引冒烟测试范围、输入输出与边界确认

## 本轮目标

只将冻结的 `STAGE-078_索引冒烟测试.md` 与已复审的 Stage077 后台索引构建合同投影为一份静态工程合同。合同定义索引版本、活动指针、构建中版本、影子索引、未来冒烟测试、失败禁止切换与回退保留边界；不构建、测试、切换、查询或持久化任何索引。

## 唯一权威与输入

- 冻结 Stage078 任务包是本阶段范围和验收的唯一来源。
- Stage077 Review 与 Stage077 已复审后台索引构建合同只作为前序控制证据；Stage078 不重定义或替代其合同。
- 不建立第二权威事实源，亦不创建第二权威事实源；来源文档与业务线白箱人工复核仍是唯一业务权威。
- 不读取、打开、解析、复制、移动或修改真实资料、原始元数据、manifest、证据账本、审计日志、报告、数据库或物理索引。

## 静态输入输出合同

1. 未来索引版本、活动指针、构建中版本和影子索引只以不透明控制字段描述；每个索引类型未来只能有一个活动版本。
2. 每次未来批量导入后必须为新候选版本安排构建，候选不得覆盖活动版本；旧活动索引在构建与未来测试期间继续服务。
3. 未来冒烟测试只接收候选版本、活动版本、资料范围、切块计数、模型引用和影子索引引用等控制字段；本阶段不执行测试，也不生成实际测试日志。
4. 只有候选构建完成、候选保持隔离、旧活动服务连续且冒烟测试完整通过后，未来原子切换才具备资格；失败、缺失或未记录结果时活动指针保持不变。
5. 未来回退只能指向保留的上一活动版本；本阶段不执行任何回退。

## 本阶段不做

- 不实现或启动数据库 schema、后台任务、索引写入、影子索引、冒烟测试、切换、回退、检索或并发读取。
- 不读取真实资料，不执行批量导入，不选择 provider 或模型，不消耗模型 Token，不调用外部 API。
- 不创建持久化记录、审计记录、缓存、队列、索引 manifest、实际冒烟日志、Operations、报告快照或已交付报告。
- 不启动 Stage078 P2、P3、P4、整阶段复审、Stage079、OVH、生产、上传或推送。

## 验收与停止

本阶段只验收静态合同、聚焦用例、机器事实投影、中文生成视图与可撤回范围的一致性。任何真实资料访问、索引构建、冒烟测试、活动指针读写、数据库连接、持久化、模型调用、Agent、OVH、生产、上传或超出 Stage078 P1 的修改都会停止本阶段。

## 回退与下一门

只撤回本 P1 的范围说明、静态合同、聚焦用例、机器事实投影、治理路线、生成中文视图和本地回执，恢复到 `PASS_REVIEWED_BACKGROUND_INDEX_BUILD_RUNTIME_DISABLED`。不影响 Stage077 Review、冻结任务包、真实资料、manifest、证据账本、审计日志、报告、数据库、索引、GitHub、OVH 或应用状态。下一步仅可在新的独立 run 进入 `IDS-STAGE078-P2-GATE`。
