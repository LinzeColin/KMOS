# Stage106 Phase 1 · 外部增强意见章节范围与边界

## 当前目标

依据冻结 STAGE-106 任务包，固定报告中外部增强意见章节的未来控制形状。外部增强意见只保留 external_public_reference 与 model_reasoning 的底层来源类型，作为独立、可审阅的章节；它不是内部项目依据，不能替代或关闭 evidence_id/evidence_gap，也不形成业务结论。

本 Phase 只形成可执行、可测试、可回滚的静态工程合同。来源文档、真实证据账本和业务线白箱人工复核继续承担业务事实权威；本合同不建立第二权威事实源。

## 固定控制范围

- 外部增强意见章节、条目、展示标签、外部公开参考、模型推理、底层来源类型和内部依据边界的未来控制引用。
- 报告关键结论仍独立关联 evidence_id 或 evidence_gap；外部增强意见不能成为内部项目依据，也不能改变证据缺口状态。
- PDF 报告未来必须显示引用来源与页码；本 Phase 不生成报告、PDF、引用内容或外部增强意见。
- data/index/evidence/model/generated_at 五项未来生成快照形状。
- 业务线白箱人工确认、报告状态影响、质量评分、导出审计、模板限制、重新生成和撤回的未来控制引用。

## 输入、输出与单一权威

输入仅为冻结 Stage106 任务包与已复审的 Stage105 报告证据绑定控制工件。输出仅为本范围说明、静态合同、聚焦白箱用例和零运行时回执。

所有 *_ref 均为不透明控制标签，不是资料、外部参考、模型输出、报告、证据、审计记录、快照或业务结论。外部增强意见的具体内容、证据等级、质量公式、报告状态规则和人工确认记录均等待业务线白箱 owner 的后续授权。

## 停止条件

以下动作属于后续授权范围：读取真实资料、原始元数据、外部参考、证据账本、已交付报告或 PDF；调用模型或消耗模型 Token；生成、展示、导出、发布、重新生成或撤回报告/PDF；生成引用；保存快照；写入报告状态、质量评分、影响分析、导出审计、数据库或持久化存储；执行人工确认、连接 OVH、激活生产、推送正式全局上传；进入 IDS-STAGE106-P2-GATE、P3、P4、整阶段 Review 或 Stage107。

## 验收与回滚

聚焦用例验证外部增强意见章节的 27 个未来控制引用、两类底层来源语义、内部依据隔离、evidence_id/evidence_gap 独立性、PDF 引用来源与页码、五项快照、业务线白箱人工确认、报告生命周期控制、失败关闭和全零运行时边界。

回滚只撤回本 Phase 的范围说明、静态合同、聚焦用例、回执、机器事实投影、治理路线、事件、生成中文视图和交接，恢复到 PASS_REVIEWED_REPORT_EVIDENCE_BINDING_RUNTIME_DISABLED。Stage105 P1--P4/Review、冻结任务包、来源文档、真实证据账本、已交付报告、审计日志、数据库、GitHub main/release、OVH 和生产状态保持原状。

下一独立 run 才可进入 IDS-STAGE106-P2-GATE。
