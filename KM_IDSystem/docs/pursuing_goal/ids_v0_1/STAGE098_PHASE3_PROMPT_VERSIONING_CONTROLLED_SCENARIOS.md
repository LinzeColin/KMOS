# Stage098 P3 · Prompt 版本化专项验证与异常场景

## 当前范围

本 Phase 只重放 Stage098 P2 自身生成的六条固定、非业务、`reference-only` 控制投影，形成六条、每条 31 字段、共 186 个检查点的纯内存异常场景。P3 仅验证：

- 检索文档继续是 evidence，文档内指令无法覆盖 IDS 规则；
- 无内部依据保持 `evidence_gap`，不会伪装为内部经验；
- 高风险工程建议、合同承诺和生产写回保持业务线白箱人工确认，最终结论未发布。

P2 的 `6 / 23 / 4 / 41 / 246` 固定控制形状保持前序事实；P3 投影五个控制视图、六条人工处理要求和十五类失败关闭。`prompt_version`、模型 provider／版本、temperature、检索上下文、查询、索引与所选 evidence 均只承载既有不透明控制引用。

## 边界

不读取或创建真实资料、提示词、查询、检索结果、回答、证据账本、审计记录、数据库或物理索引；不执行模型、模型 Token、Agent、OVH、生产、持久化、GitHub 上传或推送。P4、整阶段复审与 Stage099 保持未进入。

## 验收与回滚

验收由 P3 模块、合同、聚焦白箱用例、前序兼容链、Stage005、两个批次检查器和机器事实生成的中文视图共同记录。回滚仅撤回本 P3 的范围说明、纯内存场景模块、合同、聚焦用例、P3 治理投影、机器事实、中文视图、回执、事件和交接，恢复到 Stage098 P2；P1、P2、Stage097 Review、冻结任务包、真实资料与业务线白箱权威保持原状。
