# Stage078 Phase 2 · 索引冒烟测试最小控制切片

## 当前结论

`IDS-V0_1-STAGE078-P2` 只将冻结 Stage078 任务包、Stage078 P1 静态合同与 Stage077 Review 的前序控制边界，机械投影为五条固定、非业务、reference-only 的内存控制请求。每条请求只携带不透明的索引版本、资料范围、零切块计数、模型引用、候选/活动/上一活动版本和影子索引引用；模块只投影候选构建、冒烟门、未来原子切换候选和回退候选。

来源文档与业务线白箱人工复核仍是唯一业务权威。本切片不建立第二权威事实源，不能替代真实资料、生成物理索引、形成业务结论或自动改变活动版本。

## P2 实现的最小控制范围

- 固定五条 `:control:stage078-p2:` 输入，所有资料范围、模型、来源导入、版本、影子索引、活动和上一活动版本均是不透明控制标签，`chunk_count=0`；
- 每条控制投影记录 `index_version`、`document_scope_ref`、`chunk_count` 与 `embedding_model_ref`，候选版本、活动版本和影子引用必须彼此隔离；
- 候选构建未完成、冒烟未执行或冒烟失败时，未来切换投影必须阻断，活动指针控制投影保持不变，旧活动版本继续服务；
- 冒烟完整通过时仅产生未来原子切换候选，控制模块永不实际写入活动指针；
- 回退候选只指向保留的上一活动版本，所有构建、冒烟、切换、回退和检索均为内存控制投影，未写入数据库、索引、审计或其他持久状态。
