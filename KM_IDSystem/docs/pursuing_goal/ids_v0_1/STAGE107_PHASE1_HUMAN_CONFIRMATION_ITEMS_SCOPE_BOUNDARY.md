# Stage107 Phase 1 · 人工确认事项章节范围与边界

## 当前目标

依据冻结 STAGE-107 任务包，固定报告中人工确认事项章节的未来控制形状。停机、焊接、热处理、吊装、设备改造与合同承诺均保持为独立人工确认类别；每项未来业务使用与最终结论均以业务线白箱人工确认作为前置条件。

本 Phase 形成可执行、可测试、可回滚的静态工程合同。来源文档、真实证据账本与业务线白箱人工复核继续承担业务事实权威；本合同只保存控制引用，不形成第二权威事实源。

## 固定控制范围

- 报告证据绑定、人工确认事项章节、人工确认项、六类人工确认类别与业务线白箱确认门的未来控制引用。
- 关键结论独立关联 `evidence_id` 或 `evidence_gap`；证据等级、引用来源与页码保留为后续授权报告的字段形状。
- 外部增强意见章节保持 `external_public_reference` 与 `model_reasoning` 的底层来源语义，与内部项目依据和 `evidence_gap` 保持分离。
- `data/index/evidence/model/generated_at` 五项未来生成快照形状，以及报告快照、报告状态影响、报告质量评分与导出审计的未来控制引用。

## 输入、输出与单一权威

输入仅为冻结 Stage107 任务包与已复审的 Stage106 外部增强意见章节控制工件。输出仅为本范围说明、静态合同、聚焦白箱用例和零运行时回执。

所有 `*_ref` 均为不透明控制标签。六类人工确认事项的真实内容、人员、结论、证据等级、质量公式、报告状态规则与确认记录均等待业务线白箱 owner 的后续授权。

## 停止条件

真实资料、原始元数据、外部参考、证据账本、已交付报告或 PDF 继续由受保护边界管理。人工确认、报告/PDF 生成与导出、引用生成、快照保存、报告状态或质量评分写入、导出审计、数据库持久化、模型调用、模型 Token、Agent、OVH、生产激活、正式全局上传与 Stage107 P2 均属于后续独立授权范围。

## 验收与回滚

聚焦用例验证 25 个未来控制引用、六类人工确认类别、关键结论的 `evidence_id/evidence_gap` 独立性、外部增强来源语义、PDF 引用来源与页码、五项快照、报告交付控制、失败关闭与全零运行时边界。

回滚只撤回本 Phase 的范围说明、静态合同、聚焦用例、回执、机器事实投影、治理路线、事件与生成中文视图，恢复到 `PASS_REVIEWED_EXTERNAL_AUGMENTATION_OPINION_RUNTIME_DISABLED`。Stage106 P1--P4/Review、冻结任务包、来源文档、真实证据账本、已交付报告、审计日志、数据库、GitHub main/release、OVH 与生产状态保持原状。

下一独立 run 才可进入 `IDS-STAGE107-P2-GATE`。
