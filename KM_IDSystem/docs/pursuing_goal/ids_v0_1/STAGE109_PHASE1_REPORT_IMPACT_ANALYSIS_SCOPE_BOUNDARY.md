# Stage109 Phase 1 · 报告影响分析范围与边界

## 当前目标

依据冻结 STAGE-109 任务包，定义“引用资料更新或证据降级时识别受影响报告”的未来控制形状。报告证据绑定、外部增强章节、人工确认项、报告快照、引用资料更新、资料撤回、证据降级、索引版本变化、影响范围、受影响报告、报告状态影响和质量评分均以业务线白箱控制引用表示。

本 Phase 形成可执行、可测试、可回滚的静态工程合同。来源文档、真实证据账本、已交付报告与业务线白箱人工复核继续承担业务事实权威；本合同只保存不透明控制标签，不形成第二权威事实源。

## 固定控制范围

- 报告证据绑定、外部增强章节及其底层来源类型、人工确认项与业务线白箱确认门的未来控制引用。
- 关键结论独立关联 evidence_id 或 evidence_gap；证据等级、PDF 引用来源与页码保留为后续授权报告的字段形状。
- data/index/evidence/model/generated_at 五项报告生成快照形状，以及报告快照、引用资料更新、资料撤回、证据降级、索引版本变化、影响范围、受影响报告、受影响关键结论、报告状态影响、质量评分、导出审计、模板限制、重新生成与撤回说明的未来控制引用。
- 外部增强保持外部来源语义，业务线白箱确认保持最终业务结论与报告状态调整的前置条件。

## 输入、输出与单一权威

输入仅为冻结 Stage109 任务包与已复审的 Stage108 报告快照控制工件。输出仅为本范围说明、静态合同、聚焦白箱用例和零运行时本地回执。

所有以 _ref 结尾的字段均为不透明控制标签。真实报告、PDF、引用内容、资料更新、证据等级、人工确认、快照值、影响结果、质量分数、审计记录、模板内容、重新生成与撤回操作均由业务线白箱 owner 在后续授权流程中处理。

## 停止条件

真实资料、原始元数据、外部参考、证据账本、已交付报告或 PDF 继续由受保护边界管理。引用资料更新判断、证据降级判断、索引版本变化判断、受影响报告识别、报告生成与导出、PDF 渲染、引用生成、快照保存、报告状态或质量评分写入、影响分析、导出审计、数据库持久化、模型调用、模型 Token、Agent、OVH、生产激活、正式全局上传与 Stage109 P2 均属于后续独立授权范围。

## 验收与回滚

聚焦用例验证 33 个未来控制引用、五项生成快照、报告证据绑定、PDF 引用来源、关键结论的 evidence_id/evidence_gap 独立性、引用资料更新／资料撤回／证据降级／索引版本变化的影响触发形状、受影响报告识别、外部增强来源边界、业务线白箱门禁、失败关闭与全零运行时边界。

回滚只撤回本 Phase 的范围说明、静态合同、聚焦用例、回执、机器事实投影、治理路线、事件与生成中文视图，恢复到 PASS_REVIEWED_REPORT_SNAPSHOT_RUNTIME_DISABLED。Stage108 P1--P4/Review、冻结任务包、来源文档、真实证据账本、已交付报告、审计日志、数据库、GitHub main/release、OVH 与生产状态保持原状。

下一独立 run 才可进入 IDS-STAGE109-P2-GATE。
