# Stage080 Phase 1 · 索引回滚范围、输入输出与边界确认

## 本轮目标

只将冻结的 `STAGE-080_索引回滚.md` 与已复审的 Stage079 索引原子切换控制工件投影为一份静态工程合同。合同固定未来索引版本、活动指针、构建中版本、影子索引、冒烟测试和回滚资格；每次未来批量导入后均须隔离构建新候选，旧活动索引继续服务。合同不构建、测试、切换、检索、回滚或持久化任何索引。

## 唯一权威与输入

- 冻结 Stage080 任务包是本阶段范围和验收的唯一来源。
- Stage079 Review 与其 P1--P4 已复审控制工件只作为前序控制证据；Stage080 不重定义、不替代或扩充其字段含义。
- 不建立第二权威事实源；来源文档与业务线白箱人工复核仍是唯一业务权威。
- 不读取、打开、解析、复制、移动或修改真实资料、原始元数据、manifest、证据账本、审计日志、报告、数据库或物理索引。

## 静态输入输出合同

1. 未来索引版本、活动指针、构建中版本、影子索引和冒烟测试只以不透明控制字段描述；每个索引类型未来只能有一个活动版本。
2. 每次未来批量导入后必须为新候选版本安排隔离构建，候选不得覆盖活动版本；旧活动索引在构建、未来冒烟测试、未来切换和未来回滚准备期间继续服务。
3. 新索引未通过、缺失或未记录未来冒烟测试不得切换；构建或冒烟失败时活动指针保持不变。
4. 未来回滚只可指向保留且仍在回滚窗口内的上一活动版本；任何例外都须业务线白箱人工处理。
5. 未来构建、冒烟、切换记录与回滚证明只复用已审核的控制字段形状；本阶段不执行回滚、切换或任何记录写入。

## 本阶段不做

- 不实现或启动数据库 schema、后台任务、索引写入、影子索引、冒烟测试、活动指针读写、原子切换、回滚、检索或并发读取。
- 不读取真实资料，不执行批量导入，不选择 provider 或模型，不消耗模型 Token，不调用外部 API，不执行 Agent。
- 不创建持久化记录、审计记录、缓存、队列、索引 manifest、实际冒烟日志、切换记录、回滚证明、Operations、报告快照或已交付报告。
- 不启动 Stage080 P2、P3、P4、整阶段复审、Stage081、OVH、生产、上传或推送。

## 验收与停止

本阶段只验收静态合同、聚焦用例、机器事实投影、中文生成视图与可撤回范围的一致性。任何真实资料访问、索引构建、冒烟测试、活动指针读写、原子切换、回滚、数据库连接、持久化、模型调用、Agent、OVH、生产、上传或超出 Stage080 P1 的修改都会停止本阶段。

## 回退与下一门

只撤回本 P1 的范围说明、静态合同、聚焦用例、机器事实投影、治理路线、生成中文视图和本地回执，恢复到 `PASS_REVIEWED_ATOMIC_INDEX_SWITCH_RUNTIME_DISABLED`。不影响 Stage079 Review、冻结任务包、真实资料、manifest、证据账本、审计日志、报告、数据库、索引、GitHub、OVH 或应用状态。下一步仅可在新的独立 run 进入 `IDS-STAGE080-P2-GATE`。
