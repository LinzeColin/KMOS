# STAGE-070 Phase 4：Embedding 队列与缓存交付证据、回滚与中文反馈

## 目标与范围

本 phase 只从 P3 的五条固定、非业务、reference-only `:control:` 场景派生本地内存交付证据：策略样例、18 字段审计投影样例、零成本估算、失败处置、未外发原因、查询说明、回滚说明及克制中文反馈。

来源文档继续是唯一权威；P4 的控制元数据、审计投影、队列/缓存/重试状态和成本零值都不能成为业务事实或自动决策依据。真实策略例外仍须业务线白箱人工复核。

## 交付合同

- 五条策略样例均保留 P3 的策略、队列、缓存、重试和审计 `:control:` 引用，不含正文、摘要正文、文本块、物理路径或真实 URI。
- 每条样例都重建 P2 已冻结的 18 字段审计投影形状，Token 与成本均为零；它们不是持久审计日志。
- `denied` 明确阻断队列、缓存、重试及外发；预算不足明确暂停三者；其余三条仅为未来候选，仍要求白箱复核且不持久化、不调度。
- 五条控制引用均记录为未外发：原因只覆盖控制引用，不推断真实资料可否外发。
- 查询只在 P4 内存报告内按场景 ID、审计、策略、队列、缓存和重试控制引用核对投影；没有真实外发历史、持久审计日志、队列或缓存记录可查。

## 禁止路径与停止条件

本 phase 不读取或保留来源正文、摘要正文、chunk 文本、物理路径或真实 URI；不创建真实队列、缓存、重试、成本、模型版本或审计记录；不读取凭据，不选择 provider/模型，不初始化客户端，不调用外部 API，不消耗模型 Token，不写索引、数据库或持久状态，不运行 Agent，不部署 OVH，不启用生产，也不上传或推送。

P3 报告不可用、结果或 gate 不匹配、五条场景/29 字段/控制引用不匹配、队列缓存重试或 18 字段审计投影异常、零成本/失败处置/未外发原因/查询或回滚说明不一致，均失败关闭并停在 `IDS-STAGE070-P4-GATE`。Stage070 Review 不属于本 run。

## 可恢复与回滚

撤回仅限本说明、P4 交付模块、P4 合同、聚焦测试、machine run、事件、机器事实、路线和生成中文投影，回到 `PASS_PHASE3_EMBEDDING_QUEUE_CACHE_CONTROLLED_SCENARIOS_RUNTIME_DISABLED`。P1/P2/P3 工件保持不变；不修改冻结任务包、真实资料、fixture、manifest、evidence ledger、audit log、队列、缓存、数据库、GitHub、OVH 或应用状态。
