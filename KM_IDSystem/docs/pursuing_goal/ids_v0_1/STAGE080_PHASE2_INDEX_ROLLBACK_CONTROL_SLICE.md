# Stage080 P2：索引回滚控制切片边界

## 目标

在不读取任何 IDS 业务资料、不访问保护目录、不创建第二权威事实源的前提下，
实现一个固定输入、纯内存、reference-only 的索引版本/候选构建/冒烟门/
活动指针/回滚资格控制切片。该切片用于证明冻结任务包所需字段与失败保持
活动版本的白箱控制逻辑可以被本地验证；它不是索引构建、检索、切换或回滚
运行器。

## 唯一依据与范围

- 冻结任务包：STAGE-080_索引回滚.md。
- 已完成前置：Stage079 审查与其已审查的原子切换控制合同、Stage080 P1
  静态回滚合同。
- 不读取上述文件所指向的真实索引、数据库、导入资料、原始元数据或业务线
  内容；引用只用于控制标签和字段形状。
- 不新增业务规则、文档范围、嵌入模型或索引版本的权威事实。

## 固定控制输入

输入严格固定为五条 :control:stage080-p2: 控制请求。每条请求的
chunk_count 为 0，所有引用均为不透明控制标签，候选、活动、上一活动和
影子索引引用两两隔离。五个场景仅是非业务测试标签：

1. 已通过冒烟门的切换候选，仍不执行切换。
2. 构建未完成，活动版本保持不变。
3. 冒烟测试失败，切换被关闭且活动版本保持不变。
4. 计划切换失败，活动版本保持不变。
5. 指向保留上一活动版本且仍在控制窗口内的回滚候选，仍不执行回滚。

每条索引版本控制记录固定记录任务包要求的七个字段：
index_version、index_kind、lifecycle_state、document_scope_ref、
chunk_count、embedding_model_ref、source_import_ref。

## 控制投影与失败关闭

切片只在内存中投影以下控制记录：

- 索引版本记录、候选构建/影子隔离、活动指针；
- 冒烟测试输入与输出字段；
- 未应用的原子切换候选；
- 未应用的回滚请求资格。

候选构建未完成、冒烟输入缺失、冒烟失败、候选不隔离、计划切换失败、
回滚目标不是保留的上一活动版本、回滚窗口无效，均必须关闭切换或回滚；
活动指针投影始终保持原活动版本。回滚资格中的业务线白箱人工审批仅以
CONTROL_WHITEBOX_APPROVAL_REFERENCE_ONLY 控制标签表达，绝不代表实际审批
已经发生。
