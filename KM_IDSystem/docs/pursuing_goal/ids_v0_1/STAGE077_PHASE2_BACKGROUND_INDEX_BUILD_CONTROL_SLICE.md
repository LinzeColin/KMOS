# Stage077 Phase 2 · 后台索引构建纯内存控制切片

## 当前结论

`IDS-V0_1-STAGE077-P2` 只将冻结任务包和 Phase 1 已固定的后台索引构建合同，机械投影为五条固定、非业务、reference-only 的内存控制请求。每条请求只携带不透明的来源导入引用、资料范围引用、零切块计数、模型引用、索引类型和候选版本引用；模块只投影候选构建、影子索引、冒烟门、活动指针、未来原子切换意图和回退候选。

来源文档与业务线白箱人工复核仍是唯一业务权威。本切片不建立第二权威事实源，不能替代真实资料、形成业务结论、生成物理索引或自动改变活动版本。

## P2 实现的最小控制范围

- 复用 Stage076 已复审的三类索引版本记录、构建中版本和活动指针字段形状；候选版本与活动版本必须不同；
- 固定五条 `:control:stage077-p2:` 输入，所有资料范围、模型、来源导入、版本、影子索引、活动和上一活动版本均是不透明控制标签，`chunk_count=0`；
- 每条控制投影记录 `index_version`、`document_scope_ref`、`chunk_count`、`embedding_model_ref`，并以独立影子索引引用表示候选隔离；
- 冒烟门完整通过才产生未来原子切换候选；构建中、冒烟失败或切换失败时活动指针控制投影保持不变，旧活动版本继续服务；
- 回退候选只指向保留的上一活动版本。所有构建、冒烟、切换、回退和检索均为内存控制投影，未写入数据库、索引、审计或其他持久状态。
