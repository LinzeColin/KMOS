# Stage113 · 复核队列 Schema Phase 1 范围与控制边界

## 目标与入口

- 任务：IDS-V0_1-STAGE113-P1
- 入口门禁：IDS-STAGE113-P1-GATE
- 后续门禁：IDS-STAGE113-P2-GATE
- 冻结输入：Stage113 任务包与 Stage112 报告导出审计整阶段机械复审控制工件。

本 Phase 固定人工复核队列的未来 Schema 控制形状。低 OCR 置信度、资料冲突、解析失败和证据风险必须各自具有未来入队控制引用；待复核、已确认、已拒绝、需补资料和已归档必须作为固定状态引用。复核结果对证据可信等级和报告质量分的影响保持未来控制引用，不承载实际等级、分数或业务结论。

## P1 固定控制合同

- 复核队列项、队列 Schema、入队原因、触发类型、状态、来源、证据绑定、证据缺口、证据可信等级、报告状态与报告质量影响均只包含未来控制引用与标签。
- 低 OCR 置信度、资料冲突、解析失败和证据风险四类触发必须能指向未来待复核队列；本 Phase 不判定任何真实 OCR、冲突、解析或风险结果。
- 状态集固定为 pending_review、confirmed、rejected、needs_more_material、archived；状态转换规则、归档时机、复核结论、证据可信等级变更和报告质量分变更保持业务线白箱人工复核的后续授权。
- 每次未来复核审计保持 actor、time、reason、old_value、new_value 控制引用，并保留复核结果、重新复核、人工确认和业务线白箱门禁引用。
- 外部增强保持外部来源身份，不能替代内部证据、关闭 evidence gap 或绕过人工复核。

## 单一权威与运行时边界

- 冻结 Stage113 任务包与 Stage112 Review 控制工件构成本 Phase 的唯一工程控制上下文；来源文档、真实证据账本、已交付报告、既有审计日志与业务线白箱人工复核继续承担业务事实权威。
- 本 Phase 产物是范围说明、静态合同、聚焦用例、治理投影和本地回执。真实资料、OCR 结果、冲突、解析结果、证据风险、复核队列、复核审计、证据可信等级、报告质量分、报告状态、数据库、人工确认、模型 Token、Agent、OVH、生产和正式上传保持后续授权范围。
- 本 run 不创建队列、schema migration、复核审计、数据库或持久化记录；运行计数保持零。

## 验收、停止与回滚

- 聚焦用例必须验证四类复核触发、五个固定状态、actor/time/reason/old/new 审计控制、复核结果对证据可信等级与报告质量控制的未来引用、外部增强来源分离、业务线白箱门禁和零运行时边界。
- 缺失前序 Stage112 Review 控制、复核队列 Schema、任一触发、任一状态、审计必填引用、证据可信等级或报告质量影响控制，或者发现实际复核队列、人工确认、审计写入、数据库写入、第二权威、模型、Agent、OVH、生产或提前进入 P2 时，合同以失败状态关闭并停留在 IDS-STAGE113-P1-GATE。
- 回滚只撤回本 P1 的范围说明、静态合同、聚焦用例、machine run、治理投影、中文视图与交接，恢复 Stage112 Review 的本地零运行时状态；来源文档、真实证据账本、已交付报告、既有审计日志、数据库、GitHub、OVH 与应用状态保持既有边界。
