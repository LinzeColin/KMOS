# STAGE-053 Phase 1：按页 OCR 输出范围、输入输出与边界确认

## 当前结论

本步骤只定义 `IDS-V0_1-STAGE053-P1` 的按页 OCR 输出静态工程合同。它以冻结的 Stage053 任务包与已完成的 Stage052 中英文 OCR 整阶段本地复审为唯一合同上下文，定义未来按页 OCR 文本、置信度、图片引用和失败原因的字段边界、默认中文简体与英文、低置信度隔离、缓存与后续复核路由；没有打开任何资料、没有创建或保存任何按页输出、图片引用、缓存或审计记录，也没有选择或调用 OCR 引擎。

合同中的字段名只描述未来受控输出的结构，不是业务资料、来源正文、真实路径、页面、图片、OCR 文本、失败详情或运行结果。它不建立第二权威事实源。

## 职责交界

| 事项 | 唯一职责阶段 | 本步骤处置 |
| --- | --- | --- |
| OCR 队列基线 | Stage051 | 只引用已复审的 reference-only 输入和按页结构，不重建或运行队列 |
| 中英文 OCR 语言边界 | Stage052 | 只继承已复审的中文简体、英文和中英文混合档案，不重新定义或执行语言检测 |
| 按页 OCR 输出 | Stage053 | 定义未来输出、图片引用与失败原因的静态字段合同，不创建或保存实例 |
| 低置信度复核路由 | Stage054 | 只声明后续受控复核路由，不创建实际复核任务 |
| OCR 引擎映射与调度 | Stage055 | 不选择、配置或调用 OCR 引擎 |
| OCR 缓存保留与清理 | Stage056 | 只保留可重建缓存边界，不指定落盘位置、不写入或清理缓存 |

未来输入继续固定为 Stage052 已复审的七字段 reference-only 元数据：`source_identity_ref`、`input_kind_hint`、`parser_output_status`、`source_page_count_ref`、`language_profile`、`ocr_request_reason`、`cache_policy_ref`。这些字段不得携带来源正文、真实路径、页面内容或图片二进制。

## 按页输出、语言、置信度与失败状态合同

未来每页输出固定为 11 个字段：`source_identity_ref`、`source_page_ref`、`page_image_ref`、`ocr_text`、`language_profile`、`confidence_level`、`failure_reason`、`output_status`、`evidence_eligibility`、`cache_ref`、`review_route`。

- `page_image_ref` 只能是后续受控生成的引用，不得在本步骤创建图片、图片内容、绝对路径或原始路径。
- `ocr_text` 是后续 Stage053 运行时输出字段；本步骤不创建、保存、解释或回显 OCR 文本。
- `failure_reason` 只定义未来受控失败分类，不能保存原始异常、业务正文或来源路径；本步骤没有失败记录。
- 默认语言为中文简体与英文，允许的语言档案仍只有中文简体、英文和中英文混合；不运行语言检测。
- 置信度只定义 `HIGH`、`MEDIUM`、`LOW`、`UNKNOWN` 四个未来状态，不设数值阈值、不执行评估。低置信度、中英文混合或失败页均不能直接进入高可信证据层，只能由 Stage054 后续受控复核链处理。

缓存只能在后续作为可重建派生产物受控管理。本步骤不指定存储位置、不创建缓存、不写缓存、不清理缓存；缓存保留与清理细则仍归 Stage056。审计字段也只定义未来引用边界，本步骤不写 audit、manifest、evidence ledger、report、数据库或持久状态。

中文反馈只说明合同状态、默认语言、输出未创建、低置信度隔离、图片引用与缓存未创建；不承诺 OCR 自动化、人工复核已创建、生产可用或部署完成。

## 质量、回滚与停止条件

未来按页输出初始事实等级保持 `CANDIDATE`，质量状态保持 `UNASSESSED`。本步骤不执行质量门、不提升证据，也不把任何未来输出视为真实 OCR 或可用业务证据。

回滚只允许移除本步骤的范围说明、静态合同、聚焦用例、machine run、治理投影和生成的中文视图，并恢复到 `STAGE052_REVIEWED_LOCAL_BILINGUAL_OCR_RUNTIME_DISABLED`。真实资料、既有 evidence、运行状态、GitHub、OVH 与应用状态不在回滚范围内。

一旦需要真实资料访问、文件检测、页面渲染、图片处理、语言检测、OCR 引擎选择或调用、实际按页输出/图片引用/失败记录、缓存或复核记录、审计写入、质量门、证据提升、持久写入、Agent、模型、OVH、生产服务、Phase2、整阶段复审、批次复审、上传或推送，立即停止本步骤。
