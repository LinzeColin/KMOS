IDS-V0_1-STAGE076-P2 只把冻结任务包与 Phase 1 已固定的索引版本合同，机械投影为五条固定、非业务、reference-only 的内存控制请求。它记录不透明的 index_version、document_scope_ref、chunk_count=0 和 embedding_model_ref 控制标签，并投影构建中版本、影子候选、切换前验证、活动指针、原子切换候选和回退候选；不代表任何真实资料、索引、文档范围、文本块、模型、索引检索或运行记录。

## P2 实现的最小控制范围

- 固定覆盖 fulltext、vector、hybrid 三类索引版本，所有输入只由五条 :control:stage076-p2: 标签组成；
- 每条控制记录复用 P1 的八字段版本记录、五字段构建中版本和五字段活动指针形状；构建中候选与活动版本不同，旧活动版本继续服务；
- 影子候选保持与活动服务隔离；六项切换前验证未完成或失败时，活动指针控制投影保持不变；
- 对已声明通过的候选，仅投影未来全有或全无切换意图；切换失败时保留活动版本；回退候选只指向保留的上一活动版本；
- 所有切换、回退、检索、构建、资料范围和模型字段都是内存控制投影，未写入数据库、索引、审计或任何持久状态。
