# Stage063 Phase 2 · 章节感知切块最小可运行控制切片

## 当前目标

在 Stage063 P1 的八字段引用式输入和十四字段未来切块输出合同上，提供一个只在内存中运行的、固定且非业务的章节感知切块控制切片。它只机械验证引用字段形状、三类受保护工程语义表面、六维追溯引用和待人工复核状态能够被投影；不读取、打开、解析、检测或切分真实文档、页面、章节、表格、来源片段或 parser 输出。

## 固定控制范围

- 输入严格为三条固定的 reference-only 控制请求，分别对应 `ENGINEERING_PROCEDURE_STEP`、`ACCEPTANCE_CLAUSE` 和 `PARAMETER_TABLE`。
- 三条请求均只使用 `:control:` 引用标识。`document_ref`、`page_ref`、`section_ref`、`parser_output_ref`、`table_context_ref` 和 `source_fragment_ref` 均是不透明控制引用，不含真实路径、URL、正文、页码内容、章节文本、表格内容或 parser 输出。
- 每条请求只投影一个十四字段的章节感知切块候选；候选不是实际 chunk、事实、索引、嵌入、数据库记录或第二权威事实源。
- 候选保持为待人工复核。控制标签只证明固定合同的投影形状，不构成真实章节检测、语义资产分类、覆盖率计算、质量回归、质量降级或来源追溯绑定。

## 可执行边界

- 允许：纯内存输入字段验证、固定控制候选投影、候选形状断言、受保护表面一对一原子候选、中文反馈和拒绝未知、重排或篡改的控制输入。
- 不允许：真实文档或 parser 输出读取、章节检测、文本分割、固定字符数切割、chunk 身份/版本/哈希计算、真实语义资产分类、覆盖率计算、质量回归、质量降级判定、跨页参数表处理、来源追溯绑定、embedding、索引、数据库、持久化、Agent、模型调用、模型 Token、服务、OVH、生产、上传或推送。
- Stage064 仍拥有 chunk 身份、版本和哈希实现；Stage065 仍拥有真实语义资产分类；Stage066 仍拥有覆盖率计算；Stage067 仍拥有质量回归；Stage068 仍拥有质量降级和业务线人工处置。

## 验收与回滚

- 聚焦用例必须证明三条固定控制请求能投影为三条十四字段候选，六维追溯引用保持控制形状，三类受保护表面不被任意拆分，所有候选均要求人工复核，并拒绝异常输入。
- 回滚只撤回本 P2 说明、切片合同、纯内存模块、聚焦用例、machine run、事件、事实投影、治理路线和生成中文视图，回到 `PHASE1_CHAPTER_AWARE_CHUNKING_CONTRACT_RUNTIME_DISABLED`。
- 不触及真实资料、`00_ORIGINAL_RAW_DATA`、manifest、evidence ledger、audit log、已交付报告、事实库、索引、数据库、GitHub、OVH 或应用状态。
