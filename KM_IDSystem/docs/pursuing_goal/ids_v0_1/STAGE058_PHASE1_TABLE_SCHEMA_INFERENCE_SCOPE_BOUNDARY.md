# STAGE-058 Phase 1：表格 Schema 推断合同范围、输入输出与边界确认

## 当前结论

本步骤只定义 `IDS-V0_1-STAGE058-P1` 的静态表格 Schema 推断合同。唯一合同上下文是冻结
Stage058 任务包与 Stage057 已完成整阶段复审工件；Stage057 的 XLSX/CSV 接入合同仍是接入边界
的唯一前序合同，本步骤不复制、替换或扩展其业务事实。合同只登记未来对 XLSX/CSV、生产记录和
质检记录进行 Schema 推断时所需的抽象引用、字段候选、字段类型和停止条件；它没有读取、打开、
解析、推断、写入、复制、移动或删除任何真实表格、工作表、单元格、公式、缓存、数据库、来源
路径或业务资料。

字段名、枚举和计数仅描述未来受控实施的接口，不是工作表内容、列名、字段映射、数值、日期、
单位、设备、材料、工序、质量结果、来源正文或统计结论。因此本步骤不建立第二权威事实源。

## 职责交界

| 事项 | 唯一职责阶段 | 本步骤处置 |
| --- | --- | --- |
| XLSX/CSV 接入合同 | Stage057 | 仅引用已复审的接入边界，不重写接入合同 |
| 表格 Schema 推断 | Stage058 | 只定义未来输入、Schema profile 与字段候选合同，不执行推断 |
| 结构化事实抽取 | Stage059 | 不抽取、保留或写入事实 |

| 表格证据绑定 | Stage062 | 只定义未来引用字段，不创建来源或证据绑定 |

## 输入、Schema profile 与字段语义

未来推断输入固定为十个非内容引用字段：`source_identity_ref`、`source_document_ref`、
`file_format`、`workbook_ref`、`worksheet_ref`、`header_row_ref`、`row_range_ref`、
`column_range_ref`、`record_type` 和 `evidence_ref`。仅允许 XLSX、CSV、生产记录和质检记录；
输入不保存来源正文、物理路径、工作表、单元格或公式内容。

未来 Schema profile 固定为 18 个引用或候选字段。候选范围覆盖列名、字段类型、单位、日期、
设备、材料、工序、质量结果和事实类型，并保留来源文档、工作表、表头行、行列范围和证据引用。
这些字段在本步骤全部是静态接口：没有创建 schema profile、字段映射或推断结果。

数值统计未来只能基于带来源位置与证据绑定的结构化事实。模型不得根据文本猜测数值、字段类型
或统计结论；RAG 摘要不得替代结构化事实、成为数值统计依据或产生另一权威事实源。

## 失败、中文反馈与回滚

表头、列名、字段类型、单位、日期、设备、材料、工序、质量结果或数值无法确认时，未来流程必须
停止并交由人工处理；当前没有实际失败记录。不能自动写入业务事实、数据库或生产状态。

中文反馈只说明静态合同已定义、未来字段候选必须可追溯以及待人工处理边界，不承诺自动识别、
统计准确率、数据库可用、OVH 可用或生产可用。

回滚仅允许移除本步骤的范围说明、静态合同、聚焦用例、machine run、事件、机器事实投影和生成
中文视图，恢复到 `STAGE057_REVIEWED_LOCAL_XLSX_CSV_INGESTION_RUNTIME_DISABLED`。真实资料、
manifest、evidence ledger、audit log、已交付报告、数据库、运行状态、GitHub、OVH 与应用状态
不在回滚范围内。

一旦需要真实 XLSX/CSV、生产记录、质检表、fixture、文件检测、解析器、表格解析、实际 Schema
推断、字段识别、事实抽取、摘要、数值统计、数据库、来源位置或证据写入、持久化、Agent、模型、
OVH、生产、Phase2、整阶段复审、批次复审、上传或推送，立即停止本步骤。
