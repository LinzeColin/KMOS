## 控制边界

场景模块仅处理 P2 生成的控制标签。它不读取真实资料、原始元数据、文档正文、Prompt、回答、检索结果、证据账本、审计日志、数据库或物理索引；不选择或调用 provider、模型、Agent、外部 API、OVH 或生产服务；不生成持久化记录、业务结论、人工确认、回答发布或生产写回。

`query_ref`、`index_version_ref`、`prompt_version_ref`、`model_version_ref` 与 `selected_evidence_ref` 仅保持不透明可复现记录形状。`external_augmentation_opinion` 仅是展示标签，底层 `external_public_reference`、`model_reasoning` 与 `evidence_gap` 语义继续分离。

## 失败关闭与回退

P2 控制形状、零运行时边界或不透明引用发生漂移时，P3 返回失败报告：不产生场景、控制视图或业务记录，并保持所有运行时计数为零、运行时标记为 false。文档优先级、evidence gap 语义和高风险输出门禁的任何漂移也以明确失败状态关闭。

回退只撤回本 P3 的范围说明、纯内存场景模块、合同、聚焦用例、机器事实、治理路线、生成中文视图与本地回执，回到 `PASS_IN_MEMORY_RAG_NEGATIVE_TEST_CONTROL_SLICE_RUNTIME_DISABLED`。Stage104 P1/P2、Stage103 Review、冻结任务包、真实资料、GitHub、OVH 与应用状态保持不变。
