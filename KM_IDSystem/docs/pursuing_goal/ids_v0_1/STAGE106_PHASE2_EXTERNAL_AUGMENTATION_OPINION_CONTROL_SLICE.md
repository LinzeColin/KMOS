# Stage106 P2 · 外部增强意见章节受控最小切片

## 目标与输入

本 phase 将 P1 的 `27` 个未来控制引用和 P2 新增的 `evidence_grade_ref` 投影为五条固定、非业务、`reference-only` 的纯内存控制请求。每条请求固定外部增强意见章节、条目、展示标签、`external_public_reference`、`model_reasoning`、底层来源类型、内部依据边界、关键结论、`evidence_id` 或 `evidence_gap`、证据等级、引用来源与页码、五项生成快照、人工确认、报告状态影响、质量评分、导出审计、模板限制、重新生成与撤回引用。

关键结论在每条控制请求中严格二选一关联 `evidence_id_ref` 或 `evidence_gap_ref`。所有引用都是不透明控制标签，不是报告、证据、外部参考、模型推理、引用内容、快照、审计记录或业务结论。P3 才验证资料撤回、证据降级和索引版本变化对报告状态的影响；本 P2 不执行这些场景。

## 四组控制投影

- 报告证据绑定与章节输出：将 `evidence_id/evidence_gap`、证据等级、引用来源与页码、人工确认项和外部增强意见章节投影到未渲染的报告控制形状；PDF 引用来源与页码保持后续授权展示状态。
- 生成快照：将 `data/index/evidence/model/generated_at` 五项引用和报告快照投影为未持久化的快照控制形状。
- 报告生命周期与导出审计：将报告状态影响、质量评分、导出审计、模板限制、重新生成与撤回投影为未执行的控制形状。
- 外部增强与业务线白箱门禁：保留 `external_public_reference` 与 `model_reasoning` 的底层来源类型；外部增强不能成为内部项目依据、不能替代或关闭 `evidence_gap`；人工确认和最终结论保持业务线白箱人工前置。

## 运行时与业务边界

本切片不会读取业务资料、原始元数据、真实外部参考、模型推理输入、真实证据账本、报告或 PDF，不生成、展示、导出、保存、发布、撤回报告/PDF/引用，不保存快照，不写报告状态、影响分析、质量评分或导出审计，不执行人工确认，不连接数据库或外部服务，不调用模型、不消耗 Token、不运行 Agent、不访问 OVH、不激活生产、不上传 GitHub。控制投影只存在于函数返回值中，不形成第二权威事实源。

## 验收、停止与回滚

- 固定五条控制请求、`30` 个输入字段、四组控制投影、每条 `74` 个投影字段，共 `370` 个纯内存控制检查点。
- 任何输入漂移返回 `CONTROL_INPUT_MISMATCH`，不产生控制投影或持久化记录。
- 本 run 止于 `IDS-STAGE106-P3-GATE`；P3、P4、整阶段 Review、Stage107、正式上传、OVH 和生产保持未启动。
- 回滚只撤回 P2 的范围说明、纯内存模块、合同、聚焦用例、machine run、治理投影与生成中文视图，返回 P1 的 `PASS_EXTERNAL_AUGMENTATION_OPINION_CHAPTER_CONTRACT_RUNTIME_DISABLED`；保留 P1、Stage105 Review、冻结任务包、来源资料、真实证据账本、已交付报告、审计和主线状态。
