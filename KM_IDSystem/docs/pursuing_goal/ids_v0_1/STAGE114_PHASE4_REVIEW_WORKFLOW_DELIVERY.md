# Stage114 P4 · 复核工作流交付证据、回滚与中文反馈

## 本 run 的目标

本阶段只从 Stage114 P3 的五条固定、非业务、reference-only 专项场景派生
metadata-only 交付控制记录。五组各五条记录、两条回滚与重新复核说明、共 388 个
检查点，分别覆盖：

1. 复核队列样例；
2. 复核审计日志样例；
3. 中文 UI 流程说明；
4. 需人工判断的边界；
5. 业务线白箱确认控制；
6. 复核工作流回滚与重新复核说明。

任务包允许交付 UI 流程截图或说明。本 P4 采用可机械验证的中文流程说明；它保持
reference-only 控制语义，不渲染真实 UI 或截图，也不创建真实复核队列。

## 可交付控制形状

- 复核队列样例固定 17 个字段，引用工作流、队列、触发、状态、转移、证据绑定与
  证据风险控制；不形成真实队列项目。
- 复核审计日志样例固定 13 个字段，引用 actor、time、reason、old value、new value、
  review result、重新复核与归档控制；不写入真实审计日志。
- 中文 UI 流程说明固定 13 个字段，承接 P3 的场景中文原因，表达进入复核、显示原因、
  等待业务线白箱确认的未来流程；实际 UI、截图和用户反馈均保持未执行。
- 人工判断边界固定 15 个字段，保留 review result、evidence trust level、报告质量分
  和报告状态影响的 before/after 或未来控制引用。状态转换、可信等级、报告质量和报告
  状态写回均由业务线白箱人工确认承接。
- 业务线白箱确认控制固定 14 个字段，保留 P3 handling code、人工确认项目与门禁；
  外部增强保持底层来源与内部证据分离，不能成为内部项目证据、替代证据绑定或关闭证据
  缺口。
- 回滚与重新复核说明各固定 14 个字段，均指向
  PASS_IN_MEMORY_REVIEW_WORKFLOW_CONTROLLED_SCENARIOS_RUNTIME_DISABLED 的可验证 P3
  回退目标，并要求版本化依据、业务线白箱确认和人工确认。

## 单一权威与中文反馈

冻结 Stage114 任务包、Stage114 P1/P2/P3 控制工件和 Stage113 Review 工件只构成工程
控制上下文。来源文档、真实证据账本、已交付报告、既有审计日志和业务线白箱人工复核
继续承担业务事实权威。本 P4 不建立第二权威事实源。

中文反馈面向企业复核人员，固定说明样例、审计、UI 流程、人工判断和回退要求；它不
提供自动业务结论、自动状态转换或真实资料内容。

## 零运行时边界

真实资料、OCR、冲突、撤回、解析、证据风险、复核队列、真实 UI、审计、数据库、证据
可信等级、报告质量分、报告状态、人工确认、模型、模型 Token、Agent、OVH、生产、正式
全局上传和 push 均保持零执行。P3 形状或运行时边界漂移、样例／审计／流程／白箱／回退
字段缺失、外部增强来源混同、自动交付或写入信号出现时，模块返回失败关闭结果且不输出
交付控制记录。
