# v0.1 场景测试总表

1. 移动硬盘在线，全量扫描生成 manifest。
2. 移动硬盘扫描中被拔掉，任务进入 source_offline。
3. 移动硬盘重新接入，任务恢复。
4. 批量导入包含重复文件，系统不重复 chunk。
5. ZIP 自动解压，解压后文件重新进入 pipeline。
6. ZIP 包含路径穿越，系统阻断。
7. 扫描 PDF OCR 低置信度，进入人工复核。
8. 内置硬盘空间不足，系统暂停高风险任务。
9. 批量导入后新索引后台构建，旧索引继续服务。
10. 新索引 smoke test 失败，不切换。
11. 报告生成后可追溯 evidence_id。
12. 内部资料不足，输出 evidence_gap 和外部增强意见。
13. 外部 API 默认禁止发送 chunk。
14. owner 允许某 source 外发后，chunk 自动继承策略。
15. worker 崩溃后 job 可重试。
16. 数据库备份后可恢复 metadata。
17. 旧产品名不出现在 UI、报告、正式文档。
18. 处理失败文件出现在失败工作台。
19. 同名不同 hash 文件被识别为版本或冲突。
20. 报告引用资料更新后触发影响分析。
