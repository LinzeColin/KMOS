## 追求目标（Pursuing Goal）

计算内部证据覆盖率、引用完整率、外部增强占比、证据缺口等报告质量指标。

## Codex 执行范围

### 允许

- 只处理本 Stage 明确相关文件。
- 可以新增本 Stage 所需的代码、schema、测试、配置、文档或 UI 切片。
- 必须输出修改文件列表、真实测试结果、验收证据和回滚说明。

### 禁止

- 不得提交真实原始资料。
- 不得提交 secrets、API key、数据库密码或云端凭证。
- 不得移动、删除、覆盖 `00_ORIGINAL_RAW_DATA`。
- 不得把旧产品名用于新 UI、报告、文档显示名。
- 不得声称测试通过但没有真实测试输出。
- 不得扩大到其他 Stage 的范围。

## Phase / Task

### Phase 1：范围、输入输出与边界确认
1. 定义报告证据绑定、外部增强章节、人工确认项、报告快照、影响分析和质量评分。
2. 确认 PDF 报告必须显示引用来源。
3. 定义报告生成时的 data/index/evidence/model snapshot。

### Phase 2：实现、接入与最小可运行切片
1. 实现报告证据绑定、章节输出、快照保存、影响分析或报告质量评分切片。
2. 把 evidence_id、证据等级、引用页码、人工确认项写入报告。
3. 记录报告导出审计。

### Phase 3：报告质量评分 专项验证与异常场景
1. 验证报告关键结论有 evidence_id 或 evidence_gap。
2. 验证资料撤回、证据降级、索引版本变化会影响报告状态。
3. 验证外部增强不会被写成内部项目依据。

### Phase 4：报告质量评分 交付证据、回滚与中文反馈
1. 交付报告样例、报告快照、报告质量评分和影响分析结果。
2. 记录报告模板限制和人工确认要求。
3. 提供报告重新生成和撤回说明。
