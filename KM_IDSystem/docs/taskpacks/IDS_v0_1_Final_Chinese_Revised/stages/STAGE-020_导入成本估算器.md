## 追求目标（Pursuing Goal）

估算 embedding token、外部 API 成本、OCR 页数、索引体积和本机空间压力。

## Codex 执行范围

### 允许

- 只处理本 Stage 明确相关文件。
- 可以新增本 Stage 所需的代码、schema、测试、配置、文档或 UI 切片。
- 必须输出修改文件列表、真实测试结果、验收证据和回滚说明。

### 禁止

- 不得提交真实原始资料。
- 不得提交 secrets、API key、数据库密码或云端凭证。
- 不得移动、删除、覆盖 `00_ORIGINAL_RAW_DATA`。
- 不得把旧产品名用于新 UI、报告、文档显示名。
- 不得声称测试通过但没有真实测试输出。
- 不得扩大到其他 Stage 的范围。

## Phase / Task

### Phase 1：范围、输入输出与边界确认
1. 定义导入预检的输入目录、输出摘要、风险项、成本项和确认状态。
2. 确认预检只读取元信息，不解析正文、不修改原始文件。
3. 定义 owner 确认后才进入批量处理。

### Phase 2：实现、接入与最小可运行切片
1. 实现文件数量、格式、大小、压缩包、扫描件、预计 OCR/Embedding 工作量估算。
2. 输出风险、成本和优先级建议。
3. 把预检结果展示给 人类产品入口。

### Phase 3：导入成本估算器 专项验证与异常场景
1. 用空目录、小目录、大目录、断开移动硬盘、压缩包和空间不足样例验证预检。
2. 验证预检结果可保存、可取消、可分批、可跳过高风险文件。
3. 验证预检不会启动实际解析、OCR、Embedding 或索引。

### Phase 4：导入成本估算器 交付证据、回滚与中文反馈
1. 交付预检报告样例、风险清单和用户确认流程截图或日志。
2. 记录预检估算不确定性。
3. 交付失败解释文案和回滚方式。
