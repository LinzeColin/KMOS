## 追求目标（Pursuing Goal）

为扫描 PDF、图片和低文本覆盖 PDF 建立 OCR 任务队列。

## Phase / Task

### Phase 1：范围、输入输出与边界确认
1. 定义 OCR 输入、按页输出、语言、置信度、缓存和复核路由。
2. 确认默认中文简体和英文 OCR。
3. 定义低置信度文本不能直接进入高可信证据层。

### Phase 2：实现、接入与最小可运行切片
1. 实现 OCR 队列、按页文本输出、置信度记录或缓存保留策略。
2. 把低置信页、失败页和混合中英文页写入可解释状态。
3. 为 OCR 输出建立 source page 引用。

### Phase 3：OCR 队列基线 专项验证与异常场景
1. 用扫描 PDF、模糊图片、表格图片、中英文混合和低质量样例验证 OCR。
2. 验证低置信 OCR 自动进入人工复核或降级证据。
3. 验证 OCR 缓存不会占满内置盘，清理只清理临时产物。

### Phase 4：OCR 队列基线 交付证据、回滚与中文反馈
1. 交付 OCR 输出样例、置信度报告、失败清单和复核路由证明。
2. 记录 OCR 质量限制和人工确认提示文案。
3. 提供 OCR 缓存清理和重跑说明。
