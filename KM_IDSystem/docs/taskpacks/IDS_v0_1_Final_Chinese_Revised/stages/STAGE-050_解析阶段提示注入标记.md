## 追求目标（Pursuing Goal）

标记文档中的命令性文字为不可信内容，禁止其成为系统指令。

### 禁止

## Phase / Task

### Phase 1：范围、输入输出与边界确认
1. 定义文件类型检测、parser 路由、输出结构、fallback 和提示注入标记。
2. 确认 parser 只生成解析产物，不直接绕过质量门禁写入高可信证据。
3. 定义 text、tables、pages、sections、confidence、errors 输出合同。

### Phase 2：实现、接入与最小可运行切片
1. 实现文件签名识别、parser route、fallback chain 或差异化解析评估切片。
2. 记录 parser 版本和解析置信度。
3. 把文档中类似指令的内容标记为 evidence text，而非系统指令。

### Phase 3：解析阶段提示注入标记 专项验证与异常场景
1. 用 PDF、DOCX、XLSX、CSV、TXT、图片、未知格式和坏文件验证路由。
2. 验证 fallback 不静默丢弃，低质量解析会降级或进入复核。
3. 验证文档内提示词不会覆盖 IDS 系统规则。

### Phase 4：解析阶段提示注入标记 交付证据、回滚与中文反馈
1. 交付 parser 输出样例、fallback 日志、解析质量指标和失败分类。
2. 记录支持格式和不支持格式边界。
3. 提供 parser 版本和配置回滚说明。
