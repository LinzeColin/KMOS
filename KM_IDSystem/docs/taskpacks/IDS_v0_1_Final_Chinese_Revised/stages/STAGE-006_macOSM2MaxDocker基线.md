## Phase / Task

### Phase 1：范围、输入输出与边界确认
1. 确认 macOS、Docker、IDS_DATA_ROOT、内置盘和移动硬盘的边界。
2. 定义本机热数据、移动硬盘冷数据和 GitHub 元数据的分工。
3. 确认移动硬盘可拔插时系统的暂停、恢复和安全模式规则。

### Phase 2：实现、接入与最小可运行切片
1. 实现或记录运行环境、路径检测、状态枚举和存储预算接口。
2. 把机器端细节放入 IDS 系统运营入口，不暴露到客户操作流。
3. 为路径、空间、水位线和离线状态建立最小可运行检查。

### Phase 3：macOS M2 Max Docker 基线 专项验证与异常场景
1. 测试移动硬盘在线、离线、重新接入、权限异常和路径变化。
2. 验证本机 800GB 内置盘不会被大文件派生产物无边界占用。
3. 验证安全模式触发后大批量导入、OCR、Embedding 会暂停。

### Phase 4：macOS M2 Max Docker 基线 交付证据、回滚与中文反馈
1. 输出环境检查结果、路径检查结果、存储预算截图或日志。
2. 记录可恢复状态和不可恢复状态。
3. 交付回滚步骤和默认配置文件。
