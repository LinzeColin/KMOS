- 入口：IDS 系统运营入口

- 预计实际执行开发时间：8-16 小时

## 追求目标（Pursuing Goal）

把 Excel、CSV、生产记录、质检表按结构化数据处理，而不是全部普通文本化。

## Codex 执行范围

### 允许

- 只处理本 Stage 明确相关文件。
- 可以新增本 Stage 所需的代码、schema、测试、配置、文档或 UI 切片。
- 必须输出修改文件列表、真实测试结果、验收证据和回滚说明。

### 禁止

- 不得提交真实原始资料。
- 不得提交 secrets、API key、数据库密码或云端凭证。
- 不得移动、删除、覆盖 `00_ORIGINAL_RAW_DATA`。
- 不得把旧产品名用于新 UI、报告、文档显示名。
- 不得声称测试通过但没有真实测试输出。
- 不得扩大到其他 Stage 的范围。

## Phase / Task

### Phase 1：范围、输入输出与边界确认
1. 定义表格、生产记录、质检记录和 CSV/XLSX 的结构化处理合同。
2. 确认数值统计优先走事实库，不让模型直接凭文本猜测。
3. 定义字段类型、单位、日期、设备、材料、质量结果和事实类型。

### Phase 2：实现、接入与最小可运行切片
1. 实现表格 schema 推断、字段识别、事实抽取或表格摘要。
2. 把适合 RAG 的表格摘要与结构化事实分开。
3. 绑定表格事实到来源文档、工作表、行列范围和证据记录。

### Phase 3：XLSX/CSV 接入合同 专项验证与异常场景
1. 验证空表、合并单元格、单位混乱、日期格式不一、异常值和重复行。
2. 验证表格事实可以追溯到原始文件和行列位置。
3. 验证模型回答不能把未验证数值当成确定统计结论。

### Phase 4：XLSX/CSV 接入合同 交付证据、回滚与中文反馈
1. 交付表格事实样例、字段推断报告和数据质量测试结果。
2. 记录无法识别的表格结构和人工处理建议。
3. 提供表格重解析和事实回滚说明。
