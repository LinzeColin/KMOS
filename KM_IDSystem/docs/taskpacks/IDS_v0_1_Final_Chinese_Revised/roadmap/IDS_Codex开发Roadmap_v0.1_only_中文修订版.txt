IDS Codex 开发 Roadmap（v0.1-only 中文修订版）
========================================================================

一、使用定位
本 Roadmap 只把 v0.1 作为当前 Codex 可执行开发任务。v0.2 至 v2.0+ 只保留未来框架，不在本次执行。

二、版本路线
v0.1 → v0.2 → v0.3 → v0.4 → v0.5 → v1.0 → v1.5 → v2.0+

三、v0.1 追求目标
让 IDS 能安全接住 500GB 级驳杂资料，建立文件身份、manifest、任务状态、自动解压、解析/OCR/索引基础管线、证据引用和报告输出闭环。

四、Stage 编号规则
Stage 使用全局累计编号，不按 Domain 重置。每个 Stage 都有建议并行度、并行说明、预计实际执行开发时间。

五、v0.1 可执行 Stage

七、并行开发原则
1. 只有“建议并行度：是”的 Stage 才建议开独立 Codex thread。
2. 同一时间不要让两个 thread 修改 schema、migration、shared frontend shell、route、root governance、Docker/deploy 脚本。
3. 并行 thread 必须有不同 Stage、不同 Acceptance ID、不同文件范围。
4. 并行结束后必须执行 integration gate 或相关回归测试。
5. rclone/云端备份方案可以并行推进，但作为单独线程，不阻塞 STAGE-001 起步。
