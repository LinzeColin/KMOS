# C4 技工人工市场价（2026-09-23 云端交付）

**做了什么**：云端网络受限，只能用搜索引擎，打不开造价站和人社局的原文附件。在这个条件下收集了 7 省 2025–2026 官方人工单价和技工市场工资，整理成 `人工单价.csv`（41 行），另写了 `labor_cost.py`（统一单位、比定额和市场、算人工成本）。所有数字证据等级都是「搜索摘要-未开原文」。

**关键数字**
- 湖北定额：普工、技工、高级技工分别为 104、160、241 元/工日，2022 年起执行；2024 版改为季度指数，不再给固定单价。
- 广州造价站 2026 年 1–4 月电焊工：290–365 元/工日（含社保，不含管理费和利润）。
- 武汉 2026-08 集体协商最低日薪：电焊工 280 元。
- 武汉招聘焊工：300–420 元/天。

**差多少**：只有湖北两边都有数，市场中位 339 元，定额中位 160 元，约 2.1 倍。两边口径不一，只当量级参考。

**怎么选**：算自己的成本用市场价，焊工和钳工先按 300–420 元/天试算，再按自家社保和管理费加附加率。定额价只用来推算甲方的招标控制价。

**局限**：湖南、河南、江苏、广东省级、安徽建安口径的定额单价没查到；人社局工资价位分位数全部没查到；起重工、探伤工日薪没有。

**怎么用**：`python3 labor_cost.py summary|gap 人工单价.csv`；`cost --days 40 --daily 450 --overhead 0.25`；`test`。
