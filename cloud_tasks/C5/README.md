# C5 非主业类别公开标量（2026-09-23 云端交付）

**做了什么**：云端网络受限，只能用搜索引擎，打不开招标平台。在这个条件下对 12 个指定类别和 4 个补充类别做了约 63 次搜索，产出三样东西：
- `类别标量.csv`：每类的 3 条样例链接、每工作日估计、金额档、资质要求；
- `样例公告.csv`：55 条样例明细；
- `tender_volume.py`：本地拿到真数据后用来计数。

**关键数字**
- **每工作日条数：数不出来**，因为云端无法进平台按日期计数。
- 窗口 07-25 至 09-23 共 43 个工作日，搜索可见的维修服务类公告：起重 2 条（其中 1 条未复现），皮带机、钢结构、锅炉辅机、机加工各 1 条，其余 0 条。这只是下限，不能拿来排大小。
- 金额只拿到 2 个样本：起重维修约 40 万元/年；防腐绝热约 200 万元/年。
- 样例中确认的资质：
  - 起重：特种设备许可，B 级或以上；
  - 管道：GC2/GCD 及以上；
  - 锅炉辅机：要求有 600MW 机组辅机修理业绩。

**定性观察**：电厂检修类好搜到，但门槛高；起重维保和电机维修在水泥集团、省属国企平台常见；钢结构、管道、防腐的样例里建筑项目占多数。

**局限**：日期和金额多来自机器摘要；3 条样例的链接只是平台首页；标「常识推断」的资质没有核实。

**怎么用**：导出近 60 天的公告清单（至少有「标题或公告标题」和「日期」两列），然后运行 `python3 tender_volume.py count 清单.csv --start 2026-07-25 --end 2026-09-23`。工具会自动排除风电和备件采购，并报告跳过了多少条。

## 查了没有（逐项）
- **金额查了没有**：皮带机、钢结构、工业管道、年度维保、锅炉辅机、风机、机加工。
- **资质原文查了没有**：皮带机、钢结构、年度维保、除尘、阀门泵、耐磨防腐、风机、机加工。
- **窗口内维修服务类公告查了是 0**：工业管道、年度维保、除尘、阀门泵、耐磨防腐（工业类）、风机、电机，以及 4 个补充类。
- **平台"共 X 条"计数查了没有**：只有一条存疑线索，搜索摘要称"千里马近一年皮带机相关约 450 条"，出处页面无法确认，没有采用。
- **没查或打不开**：所有招标平台原文，全部被 EGRESS_BLOCKED 拦截。

## 统计噪声（本地计数前必读，已写进工具）
- "风机"主要命中风电机组。
- "阀门""皮带机""除尘器""电机""破碎机"主要命中备件或设备采购。
- "钢结构""防腐保温"大量命中建筑项目。
- "20万吨/年"之类的产能数字不是金额。
- 保证金、质保金也不是项目金额。

## 对抗复审结论（独立子 agent，2026-09-23，只用 WebSearch，30 次）
**抽查结果**：抽查 16 行，覆盖全部窗口内行和全部有金额或资质原文的行。
- 窗口内 6 条中 5 条可复现。廉江水泥那条未能复现，已在表里标注。
- 江投起重漏填了日期 2026-06-21 和金额约 40 万元，已补。
- 泽州那条的日期更正为 09-09，并注明偏物资采购。
- 六化建那条补上了精确链接，宁东那条补上了编号。
- 晶昊的质保金从金额列移到备注。
- 未发现凭空编造的数字。

**复审发现 4 个工具缺陷，均已从根上修复并补了测试**：
- 把"20万吨"当成金额；
- 多条公告共用平台首页链接时会被误去重；
- 列名不匹配时静默输出 0；
- 机加工的规则漏了"委外加工"。

**修复后核对**：用修复后的工具重跑 `样例公告.csv`，窗口计数与 `类别标量.csv` 一致。
