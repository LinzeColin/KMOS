# S09 / P-S09-01 · T-S09-01 —— 来源、字段映射与口径血缘

- 绑定验收：`AC-FIN-002`
- pass_gate：关键结果 100% 可追溯，**来源链断点=0**
- stop_condition：原始来源缺失且系统准备把推断值标为事实

## 断点=0 意味着推断值不能冒充事实

每个结果都带 `provenance`，`kind` 只有三种：
`measured`（来自原始凭证）、`derived`（由其它带来源的值算出）、`estimated`（推断）。

**`estimated` 不允许进入权威口径**（收入/成本/毛利/现金/应收应付）。
它可以显示、必须带标记，但不参与决策——
**推断值做决策的问题不是「可能不准」，是「没人知道它不准」。**

## 断了的链条比没有链条更危险

`derived` 的每个 input 都必须能找到。找不到就说明链条中间断了，
而断了的链条**看起来是完整的**——这正是它更危险的原因。

`lineage_breaks` 逐条查三件事：有没有来源、来源是否存在、
derived 的输入是否都存在且非空。

## 实测

`tests/test_s09_finance_core.py` —— 无来源不可追溯、推断值不得冒充权威口径、
断链检出（含「声明 derived 却没有输入」）、来源引用非空。
