# S09 / P-S09-03 · T-S09-03 —— 幂等重跑、去重与跨来源决策

- 绑定验收：`AC-FIN-003`
- pass_gate：**静默覆盖=0，重复结果=0**，冲突均可解释
- stop_condition：跨来源冲突没有可靠默认且会改变关键财务结果

## 重跑造新版本，绝不覆盖

覆盖的问题不是丢了旧值，是**丢了「为什么变了」**——
对账时唯一有用的信息恰恰是两版之间的差异。

「重复结果=0」的判据是**内容逐字节相同**才算真重复。
幂等键含版本段：同一期间的第二版数据是**新结果**，不是重复——
把它去重掉才是真正的数据丢失。

## 跨源冲突：按授权优先级裁决，且把落选的一并带出

只返回赢家等于把冲突藏起来：看报表的人不知道另一个源说的是别的数，
也就无从判断这次裁决对不对。所以返回 `winner` + `disagreement`（含差额）+ `unanimous`。

**来源不在授权优先级表里 ⇒ 停下来**，不随手选一个。
这是 stop_condition 的直接落点：没有可靠默认时不得自行裁决。

## 实测

`tests/test_s09_finance_core.py` —— 重跑造新版本、逐字节相同才 noop、
版本段防误去重、落选源带差额、一致时标 unanimous、未授权源停止。
