# S09 / P-S09-04 · T-S09-04 —— 项目经营分析与可下载报告

- 绑定验收：`AC-FIN-004`
- pass_gate：Golden Path 100%，**Black Path 数据不丢**，报告 hash/数值/来源一致
- stop_condition：报告关键数值无法通过独立 Oracle 对账

## Black Path 的要求是「数据不丢」，不是「报错友好」

出错时把已经算出来的部分连同失败原因一起返回，而不是抛掉重来。
**抛掉的代价不只是重算——用户已经填进去的东西也一起没了。**

## 报告摘要必须与键序无关

`sort_keys` 保证同样的内容产出同样的 hash，否则「报告 hash 一致」
这条验收无法自证。

## Golden Path 端到端逐项可对

从字符串金额 → 整数分 → 分析 → 分摊 → 零差额对账，全程整数，
每一步都能独立复算。这是「独立 Oracle 对账」的可执行形式。
