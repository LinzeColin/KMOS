# 压测节拍：每 30 分钟挑**一个**最久没跑的技能跑一遍（KMFA_SWEEP_RUN=1 标成压测跑）。
#
# 替代原来「部署后一口气跑 13 个」的做法——那个当天把线上打下线三次，
# 最长 5.5 分钟；nice + 拉长间隔都不够，因为问题不在参数在形状。
# 单跑一个是正常负载（排程本来天天这么跑），13 个背靠背才是突发。
# 半小时一跳、六个多小时覆盖全部，从没跑过的几小时内就会被碰到。
# 都在 6 小时内跑过时挑不出东西，这一跳什么都不做——而那是**常态**：
# 一天 48 跳、只有 13 个技能，绝大多数跳都该是空的。所以末尾的 `|| true` 不是装饰：
# 少了它，「正常的空跳」会让整行以非零退出，cron 每半小时记一笔像失败的东西，
# 真失败就淹在里面了。
*/30 * * * *  root SK=$(python3 /opt/kmfa/KMOS/KMFA/tools/pick_stalest_skill.py 2>/dev/null); if [ -n "$SK" ]; then KMFA_SWEEP_RUN=1 nice -n 19 /opt/runtime/run_skill.sh "$SK" >> /var/log/kmfa/cron.log 2>&1 || true; fi
