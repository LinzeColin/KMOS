# 备份激活：你只需在 Coolify 粘一次（一步）

## 背景
你定了「备份走 GitHub、令牌你自己创建、可以单独给我」。GitHub **不允许**用命令创建令牌(PAT)——这是它的安全限制。所以我改用**部署密钥**(deploy key,效果一样、我能创建):
- 我已建好一个**专用私有备份库** `KMFA-App-State-Backup`,并把密钥的公钥装了上去(可写)。
- 私钥我放在你本机 `_protected/kmfa_backup_deploy_key.b64`(一行文本)。**这个文件永不上传任何仓库。**
- 用专用库、不用 Private-Database:这样即便这把钥匙泄露,别人也只能碰备份,**碰不到你的财务源数据**。

## 你要做的（一次，30 秒）
1. 打开 `_protected/kmfa_backup_deploy_key.b64`,全选复制那一行。
2. 进 Coolify → skills 服务 → Environment Variables → 新增一项:
   - 名称:`KMFA_BACKUP_SSH_KEY_B64`
   - 值:粘上刚才复制的那一行
   - (勾 Secret)
3. 保存 → 重新部署 skills。

**完事。** 从此每天**北京 00:30** 自动把 App 记录异地备份到那个私有库。

## 不粘会怎样？
不粘也**不裸奔**:系统自动降级,先备到服务器自己的持久盘(能扛重新部署),启动日志会提醒你还没开异地。

我在云端真跑了完整往返:用这把密钥备份→还原→**数据一字不差**;base64 传递、entrypoint 解码也都实测通过;测试用的假数据已从备份库清干净。
